### 1.1 冥王（Ming / 史森明）

| 字段 | 值 |
|------|-----|
| **来源查证** | [B站 "你永远可以相信世界赛的冥王"](https://www.bilibili.com/video/BV1sq4y1G7oe/)、[萌娘百科](https://zh.moegirl.org.cn/%E5%8F%B2%E6%A3%AE%E6%98%8E)、[知乎讨论](https://www.zhihu.com/question/316107158) |
| **原始语境** | "你永远可以相信世界赛的冥王" 是 LPL 社区对 Ming 在世界赛（S8、S11 等）中多次出现低级失误、反向开团、迷之走位导致队伍被动局面的调侃。"冥" 谐音 "明"（Ming），"冥王" 字面义为阎王/死神，在此指代灾难级表现。 |
| **核心语义** | 辅助选手在关键比赛（尤其国际赛）中出现远超正常水准的失误频率：反向开团、技能空放、走位被秒，导致队伍节奏崩盘。 |
| **适配位置** | **仅 support** |
| **适配模式** | 排位 + 国际赛事语境（核心语义绑定世界赛表现，但数据层可用排位近似的「灾难局」替代） |
| **触发条件** | |
| — 必要条件 | 位置 = support |
| — 核心指标 | `deaths` > 同位置 P85（死亡数极高）**且** `kill_participation` < 同位置 P25（参团率极低）**且** `result = 失败**出现在高权重对局（季后赛/国际赛） |
| — 辅助证据 | `kda` < 同位置 P15；单场死亡 ≥ 6 |
| — 反证 | 若 `assists` > 同位置 P60（虽然死得多但助攻不少），降权为 neutral；若 `vision_score` > 同位置 P80（视野做得好但被抓），不触发 |
| **样本门槛** | 同位置 ≥ 10 场，最近 30 天内 |
| **褒贬风险** | **teasing（负面调侃）**。虽是调侃选手失误，但"冥王"一词本身不涉及人身攻击，属于行为描述。需注意勿在连续正面表现后触发。 |
| **认知度** | **lpl_viewer** 级别。S8-S11 年间广泛传播，"冥王"已成为 RNG 世界赛失利的标志性社区梗。 |
| **时效性** | **fading（衰减）**。Ming 2024 年底离队后曝光减少，梗的活跃度下降。 |
| **产品角色** | **sub_tag（副标签）**，仅在多场表现明显低于水准时作为"近期状态低迷"展示。不适合做主称号（负面指向过强）。 |
| **风险注意** | "冥王" 在部分语境下被误读为纯贬义人身攻击。产品层可考虑改用 "状态冰点" 或 "灾难级发挥" 等中性行为描述替代，或在 UI 中附带"这是根据你的对局数据生成的洞察，别灰心，下把杀回来！"的鼓励文案。 |

| **核心语义** | 辅助选手使用开团型英雄（尤其洛/泰坦/牛头）时，拥有极高的开团成功率和先手意识，能以肉身开团为队伍创造击杀窗口。 |
| **适配位置** | **仅 support** |
| **适配模式** | 排位 + 灵活组排 |
| **触发条件** | |
| — 必要条件 | 位置 = support |
| — 核心指标 | 近 10 场中使用开团型辅助英雄（Rakan/Alistar/Leona/Nautilus）时：`kill_participation` > 同位置 P80 **且** `assists` > 同位置 P80 |
| — 辅助证据 | `damage_taken` > 同位置 P70（吸收大量伤害）；`wards_placed` ≤ 同位置 P50（开团型辅助视野投入相对低于保护型） |
| — 反证 | 若 `deaths` > 同位置 P85（开团等于送死），降权；若使用英雄为保护型（Lulu/Janna/Soraka），不触发 |
| **样本门槛** | 同位置 ≥ 15 场，其中开团型英雄 ≥ 5 场 |
| **褒贬风险** | **positive**。褒义指向明确的主动开团能力。 |
| **认知度** | **core_fan → lpl_viewer**。"洛神" 在 RNG 粉丝中高度认知，LPL 普通观众也部分知晓，但不及 "天神下凡" 普知。 |
| **时效性** | **stable**。Ming 虽离队但洛的经典表现仍是社区记忆。 |
| **产品角色** | **sub_tag（副标签）**，搭配开团型英雄高光表现的动态标签。 |
| **注意** | "洛神" 与 Baolan 的洛也是竞争关系——Ming 和 Baolan 都以洛闻名。产品层需考虑数据区分。 |

### 1.3 大满贯 / 铁人（Meiko / 田野）

| **触发条件** | |
| — 必要条件 | 位置 = support |
| — 核心指标 | `kda` 的变异系数（`cv = std/mean`）< 同位置 P20（KDA 极稳定）**且** 同位置出场场数 > P90（大量对局） |

| — 反证 | 若 `win_rate` < 45%（稳定但一直输），不触发；若 `kda` 稳定但均在低位（稳定菜），不触发 |
| **样本门槛** | 同位置 ≥ 30 场（需长期稳定性数据） |
| **褒贬风险** | **positive**。纯粹褒义。 |
| **认知度** | **general_player** 级别。Meiko 大满贯是 LPL 标杆成就。 |
| **时效性** | **stable**。Meiko 仍活跃于 IG 战队。 |
| **产品角色** | **primary（主称号）** 候选。数据全正向，适合展示在报告 Hero 区。 |
| **注意** | "大满贯" 强调的是全面成就，"铁人"强调的是耐久和稳定性。产品层可拆为两个 sub_tag：「大满贯级稳定」「铁人出勤」。 |

### 1.4 疯牛病（通用辅助梗 — Meiko / Missing / 全体辅助）

| **核心语义** | 辅助选手使用 Alistar 时操作变形，核心技能（WQ 二连）频繁失误，开团时机极差，把该控的敌人顶走、该保的队友卖掉。 |
| **适配位置** | **仅 support** |
| **适配模式** | 排位 + 灵活 + 匹配。大乱斗不太适用（大乱斗 Alistar 更偏肉搏，二连失误成本低）。 |
| **触发条件** | |
| — 必要条件 | 位置 = support **且** 英雄 = Alistar |
| — 核心指标 | `kill_participation` < 同位置同英雄 P20（参团率极低）**或** `deaths` > 同位置同英雄 P85 |
| — 辅助证据 | `assists` < 同位置 P30；单场 Alistar 使用但 `damage_taken` < 同位置 P50（说明根本没在前排吃伤害） |
| — 反证 | 若 `kill_participation` > P50 且 `deaths` < P70（虽然有失误但整体正常），不触发；若使用英雄非 Alistar（如 Rakan/Thresh），不触发 |
| **样本门槛** | 同英雄 ≥ 5 场（Alistar 专精评估） |
| **褒贬风险** | **teasing（轻度调侃）**。主要针对操作而非选手本人。但"疯牛病"含"病"字，注意 UI 可用"今天牛头有点不听话"等高情商替代。 |
| **认知度** | **lpl_viewer** 级别。2023 夏季赛弹幕高频梗，大乱斗 Alistar 玩家也广泛知晓。 |
| **时效性** | **rising（2023 达到高峰，目前稳定）**。Alistar 只要在 meta 中保持出场，梗就会持续。 |
| **产品角色** | **sub_tag（副标签）**，仅在 Alistar 场次表现明显不佳时触发。 |

### 4.2 称号优先级规则（扩展）

Round 1 定义的优先级规则需要增加以下战队叙事的约束：

1. **战队叙事 vs 个人称号**：战队叙事型称号（翻山/涅槃/骑士归来/北伐）应在**队伍或长期多排场景**下优先于个人称号触发。
2. **逆袭型称号互斥**：翻山（2.1）、涅槃（2.2）、骑士归来（2.3）、北伐（2.4）四个逆袭型称号在同一个评估周期内互斥，最多触发一个。触发优先级：北伐（数据最明确）> 翻山 > 涅槃 > 骑士归来（数据要求最高）。
3. **辅助英雄梗按英雄触发**：疯牛病（Alistar）与勾股定理（钩子英雄）按使用英雄自动互斥。
4. **"小饱"禁用替代**：1.6 小饱的数据条件可转为"保护失位"的中性洞察，不对外展示原名。
