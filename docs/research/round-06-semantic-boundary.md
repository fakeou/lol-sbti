## 1. 核心问题：何时"选手外号"等于"行为原型"

### 1.1 问题的本质

LOL 社区的大量梗来自**选手个人**——外号、名场面、直播切片、圣经台词。当把一个选手的外号授予普通玩家时，本质上在做**语义映射**：

```
选手名/外号 → 该选手的标志性行为 → 普通玩家的同类行为
```

这个映射链条有三个环节，任何一个环节断裂都会导致"强嫁接"（forced grafting）：

| 环节 | 问题 | 强嫁接表现 |
|------|------|-----------|
| **选手→行为** | 这名选手是否因某个具体、可复现的行为而闻名？ | 选手因外貌/籍贯/私生活/ID谐音出名，而非游戏行为 |
| **行为→数据** | 该行为能否用 ≤3 个游戏指标精准描述？ | 需要"解释性故事"才能连接数据（如"精忠报国"=面对韩国队表现差） |
| **数据→玩家** | 指标触发后，玩家是否可接受被授予该称呼？ | 黑称/贬损/反讽 → 产品层不可接受 |

### 1.2 核心裁决准则

```
选手名/外号 = 行为原型  当且仅当满足以下全部：
  (1) 梗的起源是游戏行为（非外貌/私生活/ID谐音）
  (2) 该行为可用现有游戏指标描述
  (3) 触发方向与褒贬方向一致（褒义→正面数据，贬义→负面数据）
  (4) 被授予的普通玩家可以理解"为什么是我"
  (5) 不存在"反讽使用"的主导语义（如"虎大将军"社区已大量反讽）
```

## 2. 八类梗的语义边界定义

### 2.1 人物外号（Player Nickname → Behavior）

| 边界条件 | 正例 | 反例 |
|----------|------|------|
| **必须** 因游戏行为得名 | 厂长=野区养猪（反野/控图） | 马头=脸型（外貌） |
| **必须** 行为可数据化 | 雷达哥=视野/预判（可用 vision_score+deaths 逼近） | 洗澡狗=直播挂机（非游戏行为） |
| **必须** 外号本身无贬义 | 左手=左撇子+操作好（中性→褒义） | 永雏塔赞=人身攻击（贬义） |
| **禁止** 外号涉及外貌/身份 | — | 马头、鞋王、永雏塔赞、大安 |
| **风险评估** 社区是否有反讽使用 | 虎大将军→有反讽，需锁定正面触发 | 糯手→全负面无正面使用 |

**关键边界**：当选手外号的**核心传播力**来自游戏行为以外的事物（外貌、私生活、ID谐音梗、地域），且该事物不可映射为可复现的游戏行为时，**该外号不可作为行为原型**。

#### 判定清单

```
✅ "厂长" = CLEAR → 行为原型成立。因"养猪"（反野/控图）得名，行为可数据化。
✅ "左手" = CLEAR → 行为原型成立。因左撇子+操作细腻得名，CS+伤害可数据化。
✅ "雷达哥" = CLEAR → 行为原型成立。因意识好/预判准得名，视野+生存可逼近。
✅ "灯皇" = CLEAR → 行为原型成立。因稳定输出得名，伤害+死亡可数据化。
✅ "尺帝" = CLEAR → 行为原型成立。因统治级ADC表现得名，伤害+KDA可数据化。
✅ "宁王" = PARTIAL → 行为原型有但需剥离ID。Ning=冠军打野、进攻性强可映射，但"王"字辈有调侃、ID绑定（"宁"=选手名）→ 需要品牌脱敏。
✅ "世一上" = CLEAR → 行为原型成立。因自称"世界第一上单"得名，顶级数据可触发。
✅ "虎大将军" = CONDITIONAL → 行为原型成立但需锁定褒义。米勒原话为正，社区反讽为负→仅正面触发。

❌ "马头" = BLOCKED → 行为原型不成立。因外貌得名。
❌ "鞋王" = BLOCKED → 行为原型不成立。因代言/衣着得名。
❌ "永雏塔赞" = BLOCKED → 行为原型不成立。人身攻击黑称。
❌ "洗澡狗" = BLOCKED → 行为原型不成立。因直播行为（挂机洗澡）得名，非游戏行为。
❌ "公公/儒手" = BLOCKED → 行为原型不成立。人格侮辱。
```

### 2.2 比赛名句（Caster Quote → Behavior）

| 边界条件 | 正例 | 反例 |
|----------|------|------|
| **必须** 出自官方解说/官方资源 | 虎大将军=米勒解说（官方） | 永远滴神=山泥若（二路主播） |
| **必须** 名句描述的是**可复现**的行为 | "天神下凡"=一打多carry | "翻过那座山"=冠军叙事（不可复现） |
| **必须** 名句的字面=行为 | "谁敢横刀立马"=carry级伤害 | "五放皇子"=对方的BP决策（非己方行为） |
| **禁止** 单次不可复现的名场面 | — | "也许有一天"（S7 RNG vs SKT 不可复现） |

**关键边界**：比赛名句与选手名不同——名句天生有"事件绑定"。一个名句若只为特定选手的特定比赛创造，且该场景对普通玩家不可复现（如"五放皇子"依赖对方BP），则**不可作为行为原型**。只有名句描述的是**通用游戏行为**（如"天神下凡"=一打多carry），才可泛化。

#### 判定清单

```
✅ "天神下凡" = CLEAR → 一打多carry可复现。
✅ "虎大将军" = CLEAR → 单场碾压输出可复现。
✅ "不破不立" = CLEAR → 连败后连胜反弹可复现。
✅ "翻过那座山" = CONDITIONAL → 逆风翻盘通用，但非单场行为而叙事。
✅ "翻山（IG S8）" = CONDITIONAL → 同上，叙事而非单场行为。
✅ "我们是冠军" = BLOCKED → 夺冠瞬间不可复现，只适合状态文案。

❌ "五放皇子" = BLOCKED → 对方BP决策，非己方可控行为。
❌ "也许有一天" = BLOCKED → S7名场面不可复现，纯叙事。
❌ "精忠报国" = BLOCKED → 诛心论/国籍论，不可数据化且红线。
❌ "一剑开天门" = BLOCKED → TheShy 单次名场面，不可复现。
```

### 2.3 直播台词（Streamer Line → Behavior）

| 边界条件 | 正例 | 反例 |
|----------|------|------|
| **必须** 台词映射具体游戏行为 | "奇迹行者还在刷野"=打野不参团 | "克里斯关下门"=线下冲突 |
| **必须** 台词可数据化 | "三过F6而不入"（虽不可算但概念上=该刷不刷） | "假设性原则"=决策逻辑 |
| **必须** 台词不绑定主播IP | "正方形打野"已脱离大司马独立传播 | "肉蛋葱鸡"=绑大司马+酒桶 |
| **禁止** 主播私生活/线下冲突 | — | "克里斯关下门"、白银圣经 |

**关键边界**：直播台词的问题在于"主播IP绑定度"。一个梗的使用者如果必须知道主播是谁才能理解，则不适合作为面向普通玩家的行为原型。"奇迹行者"成功因为**任何打野玩家都能理解"只刷不帮"**，不需要知道姿态。"肉蛋葱鸡"失败因为**不知道大司马的人完全不知道这是什么**。

#### 判定清单

```
✅ "奇迹行者" = CLEAR → 已脱离姿态IP独立传播。打野不参团=通用行为。
✅ "正方形打野" = PARTIAL → 脱离大司马IP但概念仍在，新玩家字面可理解。
✅ "边缘OB" = PARTIAL → 已泛化出圈，LOL专属感下降但行为仍成立。
✅ "这波不亏" = PARTIAL → 通用LOL口头禅，非大司马专属。
✅ "肉蛋葱鸡" = CONDITIONAL → 绑大司马+酒桶+技能空，狭窄但精确。
✅ "挖掘机副系点什么" = BLOCKED → 队内互动无行为映射。

❌ "克里斯关下门" = BLOCKED → 线下冲突，无游戏行为。
❌ "白银圣经" = BLOCKED → 段位歧视，无游戏行为。
❌ "假设性原则" = BLOCKED → 决策哲学，不可数据化。
❌ "三七分" = BLOCKED → 主播颜值梗，无游戏行为。
```

### 2.4 数字梗（Number Meme → Behavior）

| 边界条件 | 正例 | 反例 |
|----------|------|------|
| **必须** 数字 = 具体比赛数据 | 4396 = 盲僧输出（可计算） | 777 = 幸运数字（不可计算） |

| **禁止** 数字 = 纯粉丝符号 | — | 777（Clearlove粉丝幸运数字） |

**关键边界**：数字梗是最强传播力的梗类型（4396、443、2800等），但数字的来源如果是**非游戏数据**（身高/体重/生日/粉丝梗），则不可作为行为原型。只有数字=**某场比赛的具体伤害/补刀/KDA**才可数据化。

#### 判定清单

```
✅ "4396" = CLEAR → 数字=盲僧全场输出。可映射为 damage_share < P15。
✅ "443" = CLEAR → 数字=Kid VN ADC全场输出。同上维度。
✅ "2800" = CONDITIONAL → 数字=Uzi S8输出。同上但需注意选手负面性。
✅ "2200" = CONDITIONAL → 数字=Xiaohu S9输出。同上，但当前为黑称。
✅ "777" = BLOCKED → 数字=幸运数字+粉丝梗。无游戏数据可映射。

❌ "3824" = BLOCKED → 数字=Tian身高（mm）。外貌梗，禁用。
❌ "1557" = BLOCKED → 数字=iG速通SKT时间。团队梗，非单场行为。
❌ "70512" = BLOCKED → 数字=SofM LOL ID。纯ID数字，无行为。

## 3. Semantic Fidelity 评分体系

### 3.1 五维评分

每条候选梗（聚焦"选手名=行为原型"类型）在以下五个维度独立评分，每项 0–10：

| 维度 | 权重 | 评分标准 |
|------|:----:|----------|
| **SF1: 行为起源** | 30% | 梗的起源是否直接来自游戏行为？10=纯游戏行为数据（4396），0=纯外貌/私生活（马头） |
| **SF2: 数据可算** | 25% | 行为能否用当前CSV字段描述？10=可直接计算（厂长=cs+vision），0=完全不可算（简灯笼） |
| **SF3: 方向一致** | 20% | 数据触发方向与褒贬方向是否一致？10=褒义→正面数据，0=褒义用负面数据触发（用天神下凡嘲讽） |
| **SF4: 选手剥离** | 15% | 脱离原选手后梗是否独立可理解？10=独立传播（奇迹行者），0=绑定选手ID（接Q辣舞） |
| **SF5: 反讽风险** | 10% | 社区是否大量反讽使用？10=纯正向（雷达哥），0=全反讽（CJB） |

### 3.2 综合公式

SF_Score = SF1×0.30 + SF2×0.25 + SF3×0.20 + SF4×0.15 + SF5×0.10

  8.0–10.0  🟢 A级 → 可直接上线
  6.0–7.9   🟡 B级 → 需自嘲开关/品牌脱敏
  4.0–5.9   🟠 C级 → 仅状态文案

```

## 7. 总结：可操作的产品决策树

### 7.1 决策流程

对一个候选梗，按以下顺序判定：

```
步骤1: 硬淘汰检查
  ├→ H1 红线攻击？      → 🔴 D级禁用
  ├→ H4 行为不可映射？   → ⬛ 淘汰
  ├→ H3 方向相反？       → 🔴 D级禁用
  └→ 通过 → 进入步骤2

步骤2: SF评分（五维）
  计算 SF1×0.30 + SF2×0.25 + SF3×0.20 + SF4×0.15 + SF5×0.10

  ├→ ≥8.0  → 🟢 A级 → primary / sub_tag（安全可上线）
  ├→ 6.0–7.9 → 🟡 B级 → primary/sub_tag（需自嘲开关或品牌脱敏）
  ├→ 4.0–5.9 → 🟠 C级 → 仅状态文案
  └→ <4.0   → 🔴 D级 → 禁用

步骤3: 补充检查（A/B级）
  ├→ 选手剥离度 H5 < 5？ → 追加品牌脱敏（如"宁王"→"莽王"）
  ├→ 反讽风险 SF5 < 6？ → 锁定正向数据触发+自嘲开关
  └→ 需跨位置适配？ → 限制位置
```
