## 1. 词语 vs 梗的判定标准

### 1.1 "普通词"与"梗"的分界线

在深入逐项前，先明确判定标准：

| 维度 | 普通词（Ordinary Word） | 梗（Meme） |
|:----|:----------------------|:----------|
| **起源** | 来自通用汉语/通用游戏术语，无特定诞生事件 | 有可追溯的首次出现事件（比赛/直播/解说） |
| **语义载体** | 字面义即全部义 | 字面义 + 社区附加义 |
| **传播依赖** | 无需LOL社区知识 | 需要LOL社区共识 |
| **可替代性** | 可被同义普通词替换 | 替换后丢失文化价值 |
| **示例** | "野王"=jungle king | "奇迹行者"=特定直播ID→行为描述 |

判定法则：**对于一个表达E，如果删除所有关于"这是LOL社区特有梗"的上下文后，E在LOL玩家中的理解与在非LOL玩家中的理解无显著差异，则E是普通词而非梗。**

## 2. 逐项深度分析

### 2.1 野王

#### 基本信息

| 字段 | 值 |
|------|-----|
| **字面语义** | "野"（丛林/野区）+ "王"（王者/统治者）= 野区的王者 |
| **起源** | LGD打野Eimy的社区嘲讽称呼（2016年），后泛化为"打野高手"通用词 |
| **当前使用** | 中文LOL社区中"野王"已高度泛化，类似于"打野大神"的替换词 |
| **是否为梗** | ❌ **普通词（已高度泛化）** |

#### 判定理由

1. **语义直接自明**：任何中文使用者看到"野王"都能理解为"野区之王/打野高手"，不需要知道Eimy或任何LPL背景。

2. **泛化程度极高**：在百度搜索、B站视频标题、游戏社区中，"野王"作为"打野很厉害的人"的通用称呼已极其普遍。类似"法王"（中单高手）、"辅王"（辅助高手），是"X王"体系在中文游戏圈的通用产物。

3. **LOL社区独有语义缺失**：删除LOL社区知识后，"野王"的理解无显著变化。它只是"野区"+"王"的合成词，不具有超出字面义的社区附加义。

4. **与"奇迹行者"对比**："奇迹行者"如果脱离姿态直播ID"奇迹行者"的语境，一个LOL玩家不会自动理解其为"只刷不参团的打野"——这是梗。而"野王"的"打野高手"义项不需要任何事件背景——这是普通词。

5. **R4评估的参考**：R4已确认"野王"演变后语义可褒可贬——"野王"的褒义面（野区统治力强）实际上就是通用义的"打野高手"。

6. **结论**：**"野王"不是LOL特有梗，而是中文游戏圈泛用的普通合成词。产品中如果需要"打野高手"的正面标签，直接用"野王"相当于用了一个普通形容词，而非文化梗，不符合产品定位。**

| 条件 | 结果 |
|:----|:----:|
| A. 字面有游戏语义 | ✅ 有（"野区之王"） |
| B. 可由当前字段计算 | ✅ `cs_per_min > P75 + kda > P75` |
| C. 非人物ID | ✅ 已泛化，脱离Eimy |
| D. 正面积极 | ✅ 褒义 |
| E. 适合primary | ⚠️ 但它是普通词，不是梗 |
| **总评** | **❌ 淘汰 — 普通词，非梗** |

### 2.2 节奏发动机

#### 基本信息

| 字段 | 值 |
|------|-----|
| **字面语义** | "节奏"（游戏节奏/tempo）+ "发动机"（引擎）= 游戏节奏的发起者 |
| **起源** | 中文体育/游戏评论界的通用比喻——"发动机"在体育中形容中场核心（足球/篮球），被借用到LOL中形容打野/中单 |
| **当前使用** | 广泛用于多个电竞项目（包括王者荣耀、DOTA2等），非LOL独有 |
| **是否为梗** | ❌ **普通比喻，非梗** |

#### 判定理由

1. **跨游戏通用**："节奏发动机"在中文电竞圈用于多个游戏——王者荣耀形容打野/中单，DOTA2形容二号位，守望先锋形容主T。不可能属于LOL独有梗。

2. **体育领域借用**："发动机"在足球/篮球评论中已经高度固化（"中场发动机""进攻发动机"），中文电竞评论继承了这个比喻体系。

3. **无LOL社区附加义**：删除LOL上下文后，理解无变化。"节奏发动机"="发起节奏的人/playmaker"，这是通用语义，非LOL特指。

4. **无法与LOL特有行为绑定**：与"正方形打野"（特指刷野路径）不同，"节奏发动机"描述的是"发起节奏"这个通用概念，可以贴到任何MOBA/FPS游戏的任何位置。

5. **结论**：**"节奏发动机"是中文电竞圈的通用比喻表达，不是LOL特有的行为梗。产品中使用它等于使用了一个通用评价词，与"优秀""顶尖"的区别仅在于生动了一些。**

### 2.3 控龙高手

#### 基本信息

| 字段 | 值 |
|------|-----|
| **字面语义** | "控龙"（控制龙资源）+ "高手"（专家）= 擅长控制龙资源的玩家 |
| **起源** | 直接由游戏目标"控制小龙/大龙"衍生出的朴素描述 |
| **当前使用** | 通用描述性短语，无特定事件/人物绑定 |
| **是否为梗** | ❌ **普通描述短语，非梗** |

#### 判定理由

1. **完全自明但无文化价值**："控龙高手"四个字直接描述"这个人控制龙很厉害"，没有任何超出字面的社区含义。它是描述，不是梗。

3. **无社群认同价值**：一个LOL玩家看到"控龙高手"称号的反应是"哦，他小龙打得多"，而不是"哦这是那个梗"——没有文化共鸣。

4. **结论**：**"控龙高手"甚至不是普通词，而是一个自由的描述性短语，无法作为"梗"产品化。如果产品已到需要拿"控龙高手"来填补的地步，说明打野位梗库已无泛化空间。**

### 2.4 绝食流（能否作为A级正面primary？）

#### 当前状态

R8 最终四层清单（`round-08-native-meme-core.md`）将其列为：
> **E09 绝食流** | Jungle | B sub_tag | B 🟡 | 实验层

R8 剩余项复核（`round-08-remaining-source-review.md`）则建议：
> **绝食流** 🟢 Primary，打法风格标签

**这两份R8文档在此条目上存在分歧。** 四层清单是最终裁决，剩余项复核是中间输出。需裁定是否应升级。

#### 语义分析

"绝食流" = "绝食"（停止进食）+ "流"（打法流派）。

- **游戏行为映射**：打野放弃野区资源/兵线，通过高频gank和控图建立优势。数据代理：`cs_per_min < P25 + kill_participation > P80 + deaths ≤ P50`。
- **字面语义**："不吃东西/不吃资源"——直观描述了"不吃野怪"的行为。
- **起源**：MLXG（刘世宇）RNG时期的打法风格，由LPL解说命名并推广。

#### 能否升级为A级正面primary的审查

| 审查维度 | 结论 | 理由 |
|:--------|:----:|------|
| 是否为正面/积极？ | 🔴 **有缺陷** | "绝食"本意=饥饿、不进食，是一种**自我牺牲**而非**积极进取**的隐喻。产品授予"绝食流"意味着系统在说"你吃不到资源"。虽然意图是称赞"牺牲发育换节奏"，但字面感受更接近"饿肚子"。与"轻食""低碳"等美化的减肥隐喻不同，"绝食"在中文中有明确的负面健康含义 |
| 是否适合primary？ | 🔴 **不适合** | primary是报告中最突出的主称号。"绝食流"作为主称号会让用户第一印象为"这个打野吃不到资源/发育差"——即使触发条件确保是高参团+低刷野。用户不理解"绝食"背后的积极语义（牺牲精神），只看到字面的"饥饿" |
| 是否原生梗？ | 🟡 **边界** | "绝食流"并非人物外号，而是对MLXG打法的总结性称呼。在社区中确实已作为打法流派术语使用。但有选手绑定风险 |
| 可计算性？ | 🟡 **部分可计算** | 需要过滤"被动绝食"（被反炸吃不到资源 vs 主动让资源抓人）。当前`cs_per_min < P25 + kill_participation > P80 + deaths ≤ P50`方案可近似，但有误判率 |

#### 判定

**"绝食流"不适合升级为A级正面primary。维持R8四层清单的 B sub_tag 裁定。**

理由链：
1. **sentiment 不匹配**："绝食"字面负面（饥饿→不好），无法作为"积极正面"的主称号
2. **A级要求太高**：作为A级primary，需要的是"无需解释即正面"的语义（如"天神下凡"），"绝食"需要解释"牺牲发育换节奏"才能被理解为正面——天然不适合
3. **sub_tag 是正确位置**：作为副标签+文案解释"牺牲发育换节奏"，正好发挥其"风格标签"的定位

| 条件 | 结果 |
|:----|:----:|
| A. 字面有游戏语义 | ✅ 有（不吃资源） |
| B. 可由当前字段计算 | ⚠️ 部分可计算（需反证过滤） |
| C. 非纯人物ID | 🟡 有MLXG绑定，但已部分泛化 |
| D. 正面积极 | ❌ "绝食"字面负面，不匹配A级要求 |
| E. 适合primary | ❌ 只能作为sub_tag |
| **总评** | **❌ 排除A级primary，维持B sub_tag** |

### 2.5 野区我养猪（能否剥离厂长？）

#### 基本信息

| 字段 | 值 |
|------|-----|
| **完整语句** | "你的野区我养猪" |
| **字面语义** | "养猪"在LOL语境中=把对手当猪宰/予取予求，"你的野区我养猪"=我能随意进出你的野区 |
| **起源** | Clearlove（厂长）早期Rank原话"这么菜打什么职业，回家养猪吧" → 社区反用为"你的野区我养猪" |
| **当前状态** | 已高度绑定厂长（Clearlove），是厂长的标志性台词 |

#### 剥离可行性分析

"你的野区我养猪"如果剥离厂长，发生以下变化：

| 维度 | 绑定厂长时 | 剥离厂长后 |
|:----|:----------|:----------|
| **文化重量** | LPL初代传奇打野的招牌台词，历史厚重 | 一个有趣的比喻句 |
| **用户理解** | "哦厂长那个梗" | "哦就是说我可以在对面野区随便打" |
| **情感共鸣** | LPL老玩家的集体记忆 | 无附加情感价值 |
| **梗的身份** | ✅ 是梗（有起源、有故事） | ❌ 退化为普通比喻句 |

#### 判定

**无法剥离。"你的野区我养猪"一旦剥离厂长，就从"梗"退化为"比喻句"。**

与"4396"对比：

| 对比项 | 4396 | 你的野区我养猪 |
|:------|:----:|:-------------:|
| **脱离选手后有无独立语义** | ✅ 有（数字梗=低伤害） | ❌ 无（比喻句无社区附加义） |
| **百度百科独立词条** | ✅ 有"4396"词条 | ❌ 无独立词条 |
| **作为普通词使用时是否独立于选手** | ✅ "这把我4396了"被理解 | ❌ "你的野区我养猪"仍被联想到厂长 |
| **结论** | 数字梗可剥离 | 无法剥离 |

R4 已将其定为 **C级/status**（单场状态文案）。此定位正确，不应升级。

| 条件 | 结果 |
|:----|:----:|
| A. 字面有游戏语义 | ✅ 有（入侵对面野区） |
| B. 可由当前字段计算 | ❌ 需要enemy_jungle_camps_stolen数据，当前字段不可用 |
| C. 非人物ID | ❌ 强绑定厂长 |
| D. 正面积极 | ✅ 褒义（支配力） |
| E. 适合primary | ❌ 无法剥离，不可计算 |
| **总评** | **❌ 排除 — 强绑定厂长 + 不可精确计算 + 剥离后退化为比喻句** |

## 4. 产品降级方案

由于打野位A级正面primary缺口在当前候选池中无法填补，提出以下降级方案供产品团队选择：

### 方案A：接受缺口 — 打野位最高荣誉为B级

```
打野位最高等级称号 = B级 primary（4396，需自嘲）或 B级 sub_tag（绝食流/莽王）
打野位无正面A级primary：在产品UI中标注"更多打野梗即将上线"
```

| 优点 | 缺点 |
|:----|:----|
| 诚实面对缺口，不强行凑梗 | 打野位玩家可能感到"不受重视" |
| 避免发伪梗消耗产品信任 | 与其他位置（上单/中路有A级primary）对比落差明显 |
| 为将来真正的原生梗留空间 | 产品展示层打野位无亮点主称号 |

### 方案B：原创替代 — 创建非梗行为描述称号

创建原创但语义自然的打野行为描述作为打野位正面主称号，明确标注"非社区梗"：

| 候选原创名 | 语义 | 触发条件 | 风险 |
|:---------|:----|:--------|:----|
| **"野区统帅"** | 控图+反野的全面统治力 | `vision_score > P80 + kill_participation > P70 + enemy_jungle_control`(近似) | 🟢 无文化包袱，但无梗的传播力 |
| **"节奏大师"** | 高gank高参团的节奏型打野 | `kill_participation > P85 + assists > P75` | 🟡 "大师"有轻微俗气风险 |
| **"龙族猎手"** | 小龙/大龙控制能力突出 | `dragons_killed + barons_killed > P85` | 🟢 游戏内成就风格 |
| **"反野专家"** | 入侵对方野区效率高 | 需`enemy_jungle_camps_stolen`字段 | 🟢 但缺乏文化感 |

| 建议 | |
|:----|:----|
| **接受度** | 原创称号无文化传播力，用户不会"会心一笑"，但至少填补产品空缺 |
| **推荐度** | 🟡 可接受，但需在UI明示"非社区梗称号" |
| **风险** | 无人物外号的风险，但可能被用户吐槽"没创意" |

### 方案C：跨位置A级primary替代使用

当打野玩家打出carry表现时，触发跨位置A级primary **"天神下凡"**（通用carry称号），间接覆盖打野位的正面主称号空缺。

| 优点 | 缺点 |
|:----|:----|
| 不需要打野位专有梗 | 打野玩家仍无"打野身份认同"的主称号 |
| 语义精准（团战carry） | 打野触发率可能低于上单/中单 |
| 已有P0+P1最强来源 | "天神下凡"不是打野专属，无法给打野玩家专属感 |

### 方案D（综合推荐）：方案A + 方案C 组合

> **短期：接受打野位无独立A级正面primary的事实，打野位carry表现使用"天神下凡"跨位置覆盖。**
>
> **中长期：社区追踪——关注新生代打野选手（如milkyway/银河等）是否产生可泛化的原生行为梗。当出现符合条件的梗时，优先评估填入打野位A级primary空缺。**

| 行动项 | 优先级 | 时间线 |
|:------|:------|:------|
| 打野位UI标注"更多打野梗即将上线" | 🥇 P0 | 产品首版 |

| 定期重扫中文LOL弹幕文化中的新行为梗 | 🥉 P2 | 半年审查 |
