# 深度调查第2轮：传播力与时效性（Explorer）

> 状态：Draft
> 调查范围：LPL中文圈LOL原生梗 ≥25 项
> 方法：基于可公开检索的代理指标，设计可复现的 Recognition / Half-life 评分体系
> 核心理念：**不用"经典"代替证据，每一项评分必须有可查证的代理指标支撑**

---

## 1. 方法论：Recognition & Half-life 评分设计

### 1.1 核心约束

本评分体系的根本约束：
1. **不编造数据**：弹幕量、百度指数、抖音热搜次数等均为不可稳定获取或第三方付费数据，**不使用**。
2. **可复现**：任何人使用相同方法（搜索 + 查证）应得到一致结论。
3. **代理指标优先**：用可观测的代理变量替代无法直接测量的"知名度"。
4. **区分不可获取数据**：明确标注哪些数据类型当前方法无法稳定取得。

### 1.2 数据采集协议（SOP）

```
对每个候选梗：
1. B站搜索 "[梗关键词]" → 观察搜索结果页视频数量量级、最高播放量量级
2. 百度搜索 "[梗关键词] 梗" → 检查是否有独立百科词条/被收录
3. LOL官方来源检查 → lol.qq.com 是否收录该梗
4. 萌娘百科检查 → zh.moegirl.org.cn 是否有独立条目
5. 跨平台检查 → 分别在 虎扑/知乎/微博/抖音/NGA 搜索，记录有显著结果的平台数
6. 时间跨度检查 → 记录搜索到的最早相关内容年份和最新内容年份
7. 年份复用检查 → 是否在不同年份、不同语境下被重新引用
```

### 1.3 Recognition Score（认知度，0-10分）

| 维度 | 满分 | 评分标准 |
|------|:----:|----------|
| **R1 - B站内容量级** | 3 | 核心视频最高播放量 ≥1000万(3)；≥100万(2)；≥10万(1)；<10万或无从查证(0) |
| **R2 - 百科独立词条** | 2 | 百度百科独立词条(2)；萌娘百科独立词条无百度(1)；仅在综合词条提及(0.5)；无(0) |
| **R3 - LOL官方收录** | 2 | 官方梗百科/视频中心明确收录(2)；官方语境中间接引用(1)；无(0) |
| **R4 - 跨平台分布** | 2 | B站+虎扑+知乎/微博+抖音 ≥4平台(2)；2-3平台(1)；单平台(0.5) |
| **R5 - 出圈程度** | 1 | 已在非LOL/非游戏领域被独立使用(1)；仅LOL社区(0) |

### 1.4 Half-life Score（半衰期/时效性，0-10分）

| 维度 | 满分 | 评分标准 |
|------|:----:|----------|
| **H1 - 存续年限** | 3 | 诞生至2026年 ≥10年(3)；7-9年(2.5)；4-6年(2)；1-3年(1)；<1年(0) |
| **H2 - 近期活跃度** | 3 | 2024-2026新二创/引用频繁(3)；偶有(2)；基本沉寂(1)；完全消失(0) |
| **H3 - 跨年份复用** | 2 | 可脱离原始语境在新场景复用(2)；仅限原始语境(1)；已无法独立使用(0) |
| **H4 - 衰减趋势判断** | 2 | rising/stable(2)；缓慢衰减(1)；快速衰减(0.5)；dead(0) |

### 1.5 数据可信度标注

每条证据标注可信度：
- **[OBS]** Observed — 亲自观察/搜索验证
- **[CIT]** Cited — 引用可靠来源（LOL官方、百度百科、萌娘百科、维基百科）
- **[INF]** Inferred — 基于多个来源推断，非直接观测
- **[UNA]** Unavailable — 当前方法无法获取，明确留白

### 3.2 关键对比分析

#### 3.2.1 双高区（R≥7, H≥9）

只有 **天神下凡** 和 **永远滴神/YYDS** 进入此区间。两者分别代表了两种传播路径：
- **天神下凡**：官方认证 + 名场面 + 跨年份复用
- **YYDS**：出圈泛化 → 脱离LOL成为通用语言

#### 3.2.2 高半衰期但认知度中等（H≥9, R<7）

**红温**(7.0/9.5)、**管理学**(6.0/9.5)、**边缘OB**(5.0/9.5)：
- 共同特征：已完成"出圈独立化"，不再依赖原始LOL语境
- 产品启示：这些梗的"LOL专属感"正在稀释，作为LOL产品称号的匹配度可能反而下降

#### 3.2.3 上升期梗（rising）

仅 **奇迹行者**(2023, 6.5/8.0) 和 **红温**(2018但2023-2024达到新高峰) 被判断为rising：
- 奇迹行者：B站"第三季"系列说明二创生态活跃
- 红温：从电竞黑称转变为2024年网络热词

#### 3.2.4 自然衰减规律

以下梗已进入明显的fading/dead阶段：
- **奥斯卡之夜**(2015)：历史尘埃，不再被主动提及
- **地火/湮灭/天雷**：四大渡劫名场面中三者的衰减轨迹相似——选手退役→引用频率下降→仅剩历史回顾价值
- **上流上单**(2020)：选手事件梗，选手退役后迅速衰减
- **正方形打野**(2017)：主播个人IP梗，主播停播后自然衰减

**衰减规律发现**：
1. 事件型梗（非行为描述）衰减最快——如"奥斯卡之夜""上流上单"
2. 绑定单选手的梗随选手退役衰减——但衰减速度取决于梗是否已泛化
3. 行为描述型梗（"边缘OB""红温"）完成了"去个人化"后反而不衰减

## 5. 方法局限与不足

### 5.1 当前方法可获取但精度有限

| 局限 | 说明 | 改进方向 |
|------|------|----------|
| B站播放量 | 无法精确统计所有相关视频总播放量；"量级判断"依赖搜索结果首页和人工抽样 | 若未来能获得B站API或第三方数据平台，可用精确播放量替代 |
| 跨平台分布 | "有显著结果"的判定存在主观性；不同平台搜索质量不同 | 可设计更严格的量化标准（如前10条结果中相关占比） |
| 年份复用判断 | 依赖搜索时间段筛选，但搜索引擎的时间过滤不稳定 | 可用B站视频发布时间分布数据替代 |

### 5.2 当前方法无法获取的数据

| 数据类型 | 无法获取的原因 | 替代方案 |
|----------|---------------|----------|
| **弹幕量** | B站不公开弹幕总量API；弹幕量随视频累积非线性增长 | 用视频播放量作为弱代理 |
| **百度指数** | 需要付费或企业认证账号 | 不考虑；在评分体系中不设此维度 |
| **微博热搜次数** | 历史热搜数据不公开 | 用"是否出圈"定性替代 |
| **弹幕刷屏频率** | 需要直播实时数据 | 用选手是否在役+比赛是否还在打作为代理 |
| **抖音话题播放量** | 抖音不公开精确数据 | 用"是否在抖音有显著结果"二分判断 |

### 5.3 评分体系局限

1. **R1（B站量级）的高限效应**：对于4396、YYDS这类全网传播的梗，B站播放量早已超过千万级别，"≥1000万"的3分上限无法区分它们之间的差异。
2. **H1（存续年限）对老梗有利**：诞生越早的梗自动获得更高年限分，但这不一定反映其"当前生命力"。
3. **Recognition与Half-life存在相关性**：高认知度的梗往往也有高半衰期（因为传播广→被记住的概率高），评分有部分冗余。
4. **未区分"正面传播"与"黑称传播"**：CJB和4396的评分很高，但主要是作为嘲讽梗传播——产品层面的适合性需要结合Round 1的风险评估。

### 5.4 数据获取的"时间快照"问题

本次调查在2026年7月进行。B站搜索结果会随时间变化。建议：若本项目持续推进，可每季度重新采集R1/H2数据，追踪变化趋势。

## 7. 结论与后续建议

### 7.1 核心发现

1. **可复现的评分方法成立**：基于B站量级、百科词条、官方收录、跨平台分布、出圈程度、存续年限、近期活跃度、跨年复用、衰减趋势9个维度的评分体系，可用公开检索数据支撑。

2. **传播力Top 5**（Recognition）：4396(9.0) > 天神下凡(8.0) = 永远滴神(8.0) > 红温(7.0) = 虎大将军(7.0) = 左手(7.0) = 洗澡狗(7.0) = CJB(7.0)

3. **时效性Top 5**（Half-life）：4396(10.0) = CJB(10.0) > 天神下凡(9.5) = 永远滴神(9.5) = 红温(9.5) = 虎大将军(9.5) = 管理学(9.5) = 边缘OB(9.5)

4. **传播力≠产品适合性**：CJB和4396评分极高但均为贬义/黑称，Round 1已建议不上线或谨慎使用。评价框架需要传播力×风险矩阵的双维决策。

5. **衰减有规律可循**：事件型>选手绑定型>行为描述型>已出圈独立型（衰减速度递减）。产品设计应优先选择行为描述型和已出圈独立型。

### 7.2 建议后续轮次覆盖

1. **直播弹幕文化梗**（第3轮）：弹幕是LOL梗最活跃的传播载体，但其量化测量需要专门方法
2. **二路解说放大效应**（第4轮）：DYS/姿态/水晶哥等二路直播间是梗的"加速器"
3. **抖音/快手短视频梗**（第5轮）：本轮的R4维度仅做了二分判断，需要更深入的平台特定分析
4. **新梗挖掘**（第6轮）：2023-2026年新产生的梗（如"出列""0-22"等）需要单独调查
