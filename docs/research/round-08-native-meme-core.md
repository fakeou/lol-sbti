## 1. 「原生梗优先」原则

### 1.1 定义

**原生梗（Native Behavioral Meme）**：梗的语义直接来源于游戏行为描述，不需要知道任何选手、主播或赛事背景即可理解其含义。

| 特征 | 原生梗 | 人物外号→行为化 |
|:-----|:------|:--------------|
| **语义来源** | 英雄行为/数据特征/对局现象 | 选手个人绰号/ID/经历 |
| **理解门槛** | 任何LOL玩家 | 需要LPL社区知识 |
| **脱离选手后** | 语义完整保留 | 语义严重丢失或归零 |
| **示例** | "天神下凡"=团战1v4 carry | "厂长"=Clearlove→打野控图 |

### 1.2 裁决准则

对每个候选称号，依次通过三道门：

```
门1: 梗的语义是否直接描述游戏行为？
  ├── 是 → 核心层（原生行为梗）
  └── 否 → 进入门2

门2: 脱离原选手后，字面语义是否仍携带游戏行为含义？
  ├── 是（有独立语义锚点） → 实验层
  └── 否（零或趋近零语义残余） → 禁用层（移除trigger，仅引用彩蛋）

门3（实验层追加）: 独立语义锚点的强度是否足够支撑产品使用？
  ├── 强（生理特征/字面自明） → 保留为 primary
  ├── 中（部分自明但需社区知识补全） → 保留为 sub_tag，需监控
  └── 弱 → 降为状态文案或移除
```

### 1.3 禁止操作

> **禁止"去梗化"**：不得将人物外号改写成"行为描述性普通称号"来保留产品位。
>
> | ❌ 禁止 | ✅ 允许 |
> |:-------|:------|
> | 厂长 → "野区掌控者" | 厂长 → 移除trigger，保留aliases引用 |
> | 灯皇 → "稳定输出ADC" | 灯皇 → 移除trigger，保留aliases引用 |
> | 接Q辣舞 → "走位失误ADC" | 接Q辣舞 → 移除trigger，保留aliases引用 |
>
> **理由**：去梗化后的"普通称号"已丢失原始梗的全部文化价值，产品中使用的是僵尸称号——有称号之形，无梗之魂。与其发布伪梗，不如承认该梗不适合泛化为产品称号。

## 2. L4 来源可信 — 统一修正

### 2.1 问题诊断

R7 决策矩阵将所有辅助位（护国神牛/疯牛病/勾股定理）和接Q辣舞标记为 L4 ✅，但 R7 补位来源复核发现：

- 这4项**全部无 P0/P1 来源**，仅有 P3 社区共识
- R7 补位复核建议修正为 L4 ⚠️
- 更深层问题：**R7 的 L4 标签把"工具不可抓取"与"来源不存在"混淆了**

### 2.2 L4 统一修正规则

```
L4 = 来源可信度，分两个独立维度：

origin_verified（起源可验证）：
  ├── ✅ 成立 → 需要 P0 或 P1（原始比赛录像 / 官方出品）
  ├── ⚠️ 未确认 → 仅有 P3 社区来源，无法追溯首创时刻
  └── ❌ 反证 → 有可靠证据表明起源描述为虚构

meaning_verified（语义可验证）：
  ├── ✅ 成立 → P3 多源交叉验证（≥2 个独立社区来源确认同一语义）
  ├── ⚠️ 弱 → 仅有单一 P3 来源或来源不可独立访问
  └── ❌ 不成立 → 无任何可验证来源或来源自相矛盾

⚠️ 关键声明：
  - P3 可支持 meaning_verified，不可支持 origin_verified
  - WebFetch 不可访问 ≠ 来源不存在
  - 萌娘百科/百度百科/知乎的访问拦截是工具限制，不代表原页面内容为虚假
```

| 疯牛病 | ✅ | **⚠️ origin未确认 / meaning ✅** | 同上 |

## 3. 逐项裁决：八项重点条目

### 3.1 厂长（Clearlove）

#### 语义链分析

```
"厂长" 字面语义：工厂管理者
       ↓（需要 LPL 社区知识：Clearlove = "你的野区我养猪" → 养猪场厂长）
野区掌控者（反野 + 控图 + 资历）
       ↓（数据代理）
cs_per_min > P85 + vision_score > P80 + kill_participation > P70
```

#### 裁决

| 维度 | 判定 | 理由 |
|------|:----:|------|
| **字面语义→游戏行为** | 🔴 **无自明映射** | "厂长" = 工厂管理者。一个不熟悉LPL的玩家看到"厂长"称号，不会联想到"打野控图"。映射链条需要两跳LPL社区知识 |
| **脱离选手后语义残余** | 🔴 **趋近零** | "厂长"脱离Clearlove后仅剩"工厂管理者"通用语义，与LOL打野无关 |
| **R6 SF4=8 的修正** | ❌ **SF4评分过高** | R6 认为SF4=8（"厂长字面=厂长=领导→野区领导"），但此推理已属强行延展。SF4应从8修正为**3–4** |
| **R7 source review 结论** | 支持移除 | "人物外号强行行为化"🔴最严重级别 |

**最终裁决：🔴 禁用层 — 移除 trigger，保留为 aliases 引用彩蛋。**

> - 不再作为 primary 或 sub_tag 触发
> - 保留为打野位其他产品卡（如4396、正方形打野）的 aliases 引用："在LPL社区中，Clearlove被称为'厂长'，其野区统治力……"
> - **不做去梗化替代**：不创建"野区掌控者"之类普通称号填补打野位 primary 空缺
> - 打野位 A 级 primary 从 R7 的 1 个降为 **0 个**——这是原生梗优先原则的代价，需在后续轮次探索新的原生行为梗填补
