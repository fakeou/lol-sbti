# objective

实现 `apps/web` 临时报告网页。页面读取 `/r/{publicId}#{shareSecret}`，在浏览器端将 fragment secret 兑换为 HttpOnly session，立即清理地址栏，再展示严格结构化 LBTI 报告。实现加载、无效、过期/撤销、字段不足和响应式状态；不得使用第三方资源、dangerouslySetInnerHTML 或客户端持久化 secret。
