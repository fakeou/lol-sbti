# 深度调查第3轮：可上线候选漏斗（Explorer）

> **状态**：Final
> **轮次**：Explorer Round 3 — 安全可计算漏斗
> **来源**：综合 Round 1 评价框架 + Round 2 四份调查（传播力、现代赛事、解说官方、辅助与战队）共 107 项梗
> **目标**：筛出可被常规比赛汇总数据触发、普通玩家可理解、无红线风险的梗，分为 A/B/C/D 四级
> **日期**：2026-07-24

## 0. 漏斗方法论

### 0.1 筛选标准

每条候选梗必须同时通过以下四关：

| 关卡 | 标准 | 淘汰条件 |
|------|------|----------|
| **第1关：数据可计算** | 所有触发指标在当前 CSV 字段中可计算或可派生；不需要聊天记录、地图事件、社交图谱等不可获取数据 | 需要爆炸果实事件、锤石灯笼位置、对方 ban/pick 记录、地理信息、MMR 精确值、聊天内容 → **直接淘汰** |
| **第2关：安全红线** | 不涉及外貌羞辱、地域/种族歧视、选手私生活、严重黑称、已被官方警告的称呼 | 涉及上述任何一项 → **D 级禁用** |
| **第3关：语义不强行嫁接** | 触发数据与梗的原义方向一致、行为模式可映射、不"为了用梗而造规则" | 语义与触发数据方向相反、需要"解释"才能自洽、核心含义依赖不可获取数据 → **降级或淘汰** |
| **第4关：普通玩家可理解** | 不依赖对特定选手/主播/历史事件的深度了解，梗的字面或圈内常识即可理解 | 仅 core_fan 可懂、脱离原始语境无法独立理解 → **降级 C 或淘汰** |

### 0.2 分级定义

| 等级 | 标识 | 含义 | 产品角色 |
|------|:----:|------|----------|
| **A 上线** | 🟢 | 安全、可计算、语义自洽、认知度高。可直接作为主称号或副标签上线。 | primary / sub_tag |
| **B 需自嘲开关** | 🟡 | 可计算但含轻度调侃/贬义/情绪代理，需用户主动开启"自嘲模式"后才能展示。 | primary / sub_tag（需开关） |
| **C 仅状态/引用** | 🔵 | 可计算但语义过窄/过轻/过时/依赖特定英雄，仅适合单场状态文案或名场面引用。 | status（状态文案） |
| **D 禁用** | 🔴 | 触发红线或不可计算且语义强嫁接。任何产品层不得展示。 | hidden |
| **— 淘汰** | ⬛ | 不可计算+语义无法映射，或认知度过低。不纳入任何产品层。 | — |

### 0.3 数据可计算性判定细则

基于 Round 1 §3 的可用指标（kills, deaths, assists, KDA, kill_participation, cs, cs_per_min, gold, gold_per_min, damage_dealt, damage_share, damage_taken, healing, vision_score, wards_placed, wards_killed, result, position, queue, duration_minutes 及其聚合），以下场景判定为**不可计算**：

- 需要地图事件数据（爆炸果实、灯笼位置、抢龙事件识别）
- 需要对手行为数据（对方 ban/pick、对方聊天、MMR 精确值）
- 需要社交图谱数据（前队友关系、地区/学校、组排历史对手识别）
- 需要聊天/语音数据（"嘴硬""阴阳怪气""预测发言"）
- 需要视觉/事件级数据（"W 顶走残血""护盾方向""技能空放次数"）
- 需要特定对手/特定队伍的历史对阵数据（但可通过简化方案部分缓解）

## 1. 统一裁决：争议梗

以下梗在多轮调查中有冲突判断，Round 3 给出最终裁决：

### 1.1 虎大将军

| 维度 | 裁决 |
|------|------|
| **起源** | 2017 LPL 夏半决 RNG vs WE 第5局，米勒解说："谁敢横刀立马，唯我虎大将军！"Xiaohu 飞机打出 9 万输出 |
| **语义演变** | 2020 年后 Xiaohu 世界赛表现不佳，社区反向使用"虎大将军"进行嘲讽（等同于"2200""虎大捞比"） |
| **裁决** | **A 级（正面触发 only）**。只在小虎式 carry（中单位置 damage_share > P90 + kills 极高 + 胜利）时触发，保留米勒原话的褒义。**禁止设计负面触发**——社区的讽刺使用是社区行为，产品不应复制。触发条件必须严格到"不达标的玩家拿不到这个称号"，自然杜绝反讽空间。 |
| **反证** | 若 damage_share < P75 或 result = 失败 → 一票否决 |
| **注意** | 与"左手"可能有语义重叠（都是中单 carry），但虎大将军强调单场爆发（9 万输出 = 极高伤害），左手强调持续压制（高 CS + 高伤害均值）。数据层面可区分。 |

### 1.2 洗澡狗

| 维度 | 裁决 |
|------|------|
| **起源** | 2015 年 Uzi 在直播中因游戏不顺挂机去洗澡，社区称"洗澡狗"。后演变为 Uzi 核心黑称。 |
| **裁决** | **D 级禁用**。"洗澡"涉及选手私生活（直播行为），"狗"为严重贬称。虽 Riot 2024 年以守卫眼皮肤玩梗，但不代表适合授予普通玩家。**无游戏行为映射，仅为身份攻击。** |
| **传播力** | R2 传播评分 7.0/7.0，但传播力≠产品适合性 |

### 1.3 CJB / 冲击波

| 维度 | 裁决 |
|------|------|
| **起源** | 2015 年社区梗，拼音缩写"吹JB"，意为"吹牛/被高估"。百度百科独立词条。 |
| **裁决** | **D 级禁用**。虽传播力极强（R9.0/H10.0），但语义定义为"对他人能力的否定性贬低"，作为系统授予的称号会对玩家造成人格否定。**不可上线。** |
| **注意** | CJB 的出圈证明了梗的生命力，但这恰恰是风险——普通玩家可能理解为"系统在骂我是吹牛X"，引发投诉。 |

### 1.4 马头

| 维度 | 裁决 |
|------|------|
| **起源** | TheShy 外貌黑称（脸型偏长→马脸），由主播炫神等人推动 |
| **裁决** | **D 级禁用**。Round 1 已明确：外貌羞辱、IG 官方投诉、LPL 官方警告。**任何产品层不得出现。** |
| **替代** | 若需描述 TheShy 的"状态低迷"面，使用行为描述"状态低迷"或"最近需要调整"，不使用任何与外貌相关的称呼 |

### 1.5 精忠报国

| 维度 | 裁决 |
|------|------|
| **起源** | 2023 S13 八强 LNG 0:3 T1，Tarzan/Scout 作为韩援面对 LCK 队伍表现失常，社区刷"精忠报国" |
| **裁决** | **D 级禁用**。涉及国籍论和"故意放水"的诛心指控——暗示选手不职业、背叛队伍。这不仅是人身攻击，更涉及民族情绪煽动。**不可上线。** |
| **缓和** | Tarzan 2024 在 WBG 证明实力后舆论有所缓解，但梗的核心（国籍=忠诚度判断）是不可接受的预设 |

### 1.6 及时雨送姜 / 宋江 / 送姜

| 维度 | 裁决 |
|------|------|

| 黑称 | 裁决 | 理由 |

| 小饱 | **D** | "饱了"=下饭贬低，虽不涉外貌但负面指向过强。数据条件可内留但不对外展示 |
| 越南腐乳 | **D** | 国家羞辱+战俘隐喻，极度敏感。TES 粉丝至今反感 |
| 月男腐乳/出列 | **D** | "腐乳"=羞辱，"出列"=审判，有公开处刑感。绑定 JackeyLove，不适合泛化 |

#### A-TOP-01：369骰子

| 字段 | 值 |
|------|-----|
| **原义** | 369 选手状态极度不稳定——"3"时拉跨，"6"时平庸，"9"时战神，被比作骰子 |

### 7.2 打野位薄弱分析

打野位仅 3 个 A+B（不含跨位天神下凡），主要原因是：
1. **可计算的打野梗天然少**：打野行为多涉及 gank 路线、反野节奏、龙区控制等需要事件级数据的能力，常规比赛汇总数据难以捕捉。
2. **4396 虽可计算但为 B 级**：数字伤害梗存在但为自嘲类。
3. **五放皇子/果皇等因不可计算淘汰**。

**缓解方案**：
- "天神下凡"跨位置覆盖 top/jungle/mid，打野可被授予
- "奇迹行者"作为打野专用 primary 称号，覆盖率最高
- 未来版本若获取事件级数据（抢龙、反野成功次数等），可挖掘更多打野梗

## 10. 后续建议

### 10.1 阈值校准
所有 P25/P75/P80/P90 等百分位阈值为假设值（基于 Round 1 框架），需用真实对局数据验证分布。建议在 10000+ 玩家样本上做描述性统计，确定各位置的 KDA/伤害/参团率等指标的实际分位值。

### 10.2 优先上线范围
建议首批上线以下 A 级 primary 称号（覆盖全位置+高认知度）：
1. 奇迹行者（jungle）
2. 369骰子（top）
3. 左手（mid）
4. 暴毙AD（bottom）
5. 大满贯/铁人（support）
6. 天神下凡（top/jg/mid）
7. 永远滴神/YYDS（any）
8. 翻山（any）
9. 涅槃（any）

### 10.3 需要技术预研的能力
- **对手追踪**：丞相/孟获 需要同一对手的多次交手记录（opponent_id）
- **段位历史**：骑士归来/御三家 需要历史最高段位/账号注册时间
- **出装数据**：虎三件 需要 item_purchases
- **团灭检测**：永不团灭 需要团队同时死亡事件
- **连胜/连败模式**：红温 需要按时间序列分析 tilt 模式

### 10.4 合并建议
- 洛神 + 冠军洛 + 洛王 → 合并为"洛精通"（1 个称号 × 3 个内部风格分型）
- 不破不立/翻山/涅槃/骑士归来/北伐 → 保持独立但一个周期内互斥（最多触发 1 个）

### 10.5 用户研究
- 自嘲开关的用户接受度测试（B 级称号的展示效果）
- "红温"情绪代理的合法性评估（法务+用户感知）
