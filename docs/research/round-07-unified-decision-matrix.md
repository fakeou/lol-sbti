## 1. 最终裁决优先级体系（L1–L6）

### 1.1 六级优先级定义

```
L1 > L2 > L3 > L4 > L5 > L6

每一级对下级有独立否决权。
即：L2 不通过时，L3–L6 的任何高分都不能将产品升级。
    L3 不通过时，L4–L6 的任何高分都不能将产品升级。
```

| 优先级 | 名称 | 决策语义 | 否决条件 | 典型场景 |
|:-----:|:-----|:--------|:--------|:--------|
| **L1** | 🔴 安全红线 | 一票否决，D级禁用 | 外貌/人格/国籍/种族/私生活攻击；官方警告；法律风险 | 马头、CJB、精忠报国 → D |
| **L2** | 🟠 可计算性 | 字段不可获取→淘汰；代理弱→降级 | 核心语义需要的字段不可获取且无合理简化方案 | 翻山(opponent_rank缺失)→淘汰；雷达哥(vision_score中代理)→降B |
| **L3** | 🟡 语义保真 | SF五维评分：方向一致、选手剥离、反讽风险等 | SF<4.0→D；SF 4.0–5.9→C；SF≥6.0→进入L4–L6评估 | 宁王H5=4→需品牌脱敏；虎大将军SF5=3→需自嘲开关 |
| **L4** | 🟢 来源可信 | 证据等级 P0–P4 + origin_verified | P0缺失且无P1补位→降产品级至多B | 奇迹行者P0未定位→降产品级至B（GAP-X1） |
| **L5** | 🔵 认知度 | 目标用户认知度百分比 | <60%→淘汰或降为别名/状态；60–75%→降B | 右手<60%→移除trigger；正方形打野fading→降B |
| **L6** | ⚪ 传播力 | 传播强度与半衰期 | 仅在同级PK时作为tiebreaker，不独立升降级 | 369骰子>世一上的传播力差异不影响产品级 |

### 1.2 优先级否决链图解

```
候选梗
  │
  ├── L1 安全红线 ──── ❌ → 🔴 D级禁用（不可挽救）
  │     ✅
  ├── L2 可计算性 ──── ❌ → ⬛ 淘汰（字段不可获取）
  │     ✅              ⚠️ → 🟡 降B（代理弱/外部维表依赖）
  │     ✅
  ├── L3 语义保真 ──── SF<4.0 → 🔴 D
  │     ✅             SF 4.0–5.9 → 🟠 C（仅状态文案）
  │     ✅             SF≥6.0 → 进入L4
  │     ✅
  ├── L4 来源可信 ──── P0缺失+P1弱 → 最高B级
  │     ✅
  ├── L5 认知度 ─────── <60% → 淘汰/别名
  │     ✅              60–75% → 降B
  │     ✅
  └── L6 传播力 ─────── tiebreaker only
        ✅
      最终产品级 = MIN(L1_pass, L2_pass, L3_derived, L4_derived, L5_derived)
```

### 1.3 与 Round 6 语义边界文档的差异

| 维度 | round-06-semantic-boundary | round-07 本裁决 |
|:-----|:--------------------------|:----------------|
| SF的角色 | SF综合分直接决定产品级（A/B/C/D） | SF仅决定L3层"是否语义自洽"，不决定最终产品级 |
| 可计算性 | 作为SF2子维度（权重25%） | **升级为独立L2层，对L3有否决权** |
| 安全红线 | 作为H1硬淘汰条件 | **升级为独立L1层，最高优先级** |
| 认知度 | 不纳入SF评分 | **升级为独立L5层，<60%独立否决** |
| 来源可信 | 不纳入SF评分 | **升级为独立L4层，P0缺失可降产品级** |

## 2. 重新校准 semantic_fidelity 的决策边界

### 2.1 核心声明

> **semantic_fidelity（SF）是"语义映射是否自洽"的度量，不是"产品是否应该上线"的度量。**
>
> SF 回答的问题是："这个梗的语义能不能合理地映射到游戏行为数据？"
> SF **不能**回答的问题是："这个梗是否安全？数据能不能算？用户认不认识？"

### 2.2 SF 的有效决策范围（重新划定）

| SF 区间 | L3 层判定 | 能否独立定产品级？ | 说明 |
|:------:|:---------|:----------------:|:----|
| **SF ≥ 8.0** | ✅ 语义自洽 — "梗→行为→数据"映射链条完整 | ❌ **不能**。L1/L2/L4/L5 可独立否决 | 如雷达哥 SF=9.35 但 L2(可计算性) 代理弱 → 降B |
| **SF 6.0–7.9** | ⚠️ 语义部分自洽 — 存在一个或多个维度缺陷 | ❌ **不能**。需结合L4/L5判断 | 如虎大将军 SF3=6(方向不一致风险) + SF5=3(反讽) → B级 |
| **SF 4.0–5.9** | ❌ 语义弱 — 映射链条有断裂 | ✅ **可以**独立降至C级 | 如边缘OB SF=6.50但实际为C级状态文案 |
| **SF < 4.0** | ❌ 语义不成立 — 硬嫁接 | ✅ **可以**独立淘汰至D | 如下饭已完全泛化无LOL专属语义 |

### 2.3 SF 不能做什么（硬约束清单）

| 约束 | 内容 | 反例 |
|:----:|:----|:----|
| **C1** | SF 不能掩盖安全问题 | 马头若强行做SF评分可能SF1=0(H1外貌)而非SF1=5，但L1直接否决，**无需进入SF评分** |
| **C2** | SF 不能弥补字段缺口 | 翻山若强行做SF评分可能SF2=0，但L2(opponent_rank不可获取)直接淘汰，**无需进入SF评分** |
| **C3** | SF 不能替代认知度判断 | 右手 SF=8.50(A)，但L5(认知度<60%)独立否决trigger，保留为别名 |
| **C4** | SF 不能消除反讽风险 | 虎大将军 SF5=3 记录了反讽风险，但产品层只能通过自嘲开关缓解，不能通过SF高分"证明安全" |
| **C5** | SF 不能为代理强度背书 | 雷达哥 SF2=8 对"vision_score代理预判能力"打了高分，但该代理的实际强度是L2(可计算性)的判断，非SF的判断 |

### 2.4 SF 的剩余有效用途

1. **语义自洽验证**：确认梗→行为→数据映射链条是否完整（L3层的核心功能）
2. **问题定位**：当产品级与预期不符时，定位是"语义本身有问题"(SF低)还是"其他维度有问题"(L2/L4/L5低)
3. **优先级排序**：在L1–L5全部通过的前提下，SF高分梗优先于SF低分梗
4. **品牌脱敏指导**：SF4(选手剥离度)低的梗需要品牌脱敏（如宁王H5=4→"莽王"）

## 3. 四个争议案例的最终裁决

### 3.1 雷达哥：SF=9.35(A) vs 产品=B sub_tag

#### 冲突全景

| 来源 | 判定 | 理由 |
|:----|:----|:----|
| `round-06-semantic-boundary.md` §3.3 | SF=9.35 🟢 A级 | SF1=10(纯游戏行为)，SF2=8(可算)，SF3=10(方向一致)，SF4=9(选手剥离)，SF5=10(无反讽) |
| `round-06-semantic-boundary.md` §5.5 | primary（主称号），"本批次最安全的称号之一" | — |
| `round-06-product-card-reconciliation.md` §1.2 | B sub_tag（降级） | vision_score为中等强度代理；deaths<P25为弱代理；kill_participation>P65与宁王重叠 |
| `round-05-jungle-conflict-remediation.md` §2 | A primary → B sub_tag | 语义代理降级裁决 |

#### L1–L6 逐层裁决

```
L1 安全红线    │ ✅ 通过。无外貌/人格/国籍攻击，无官方警告。
              │
L2 可计算性    │ ⚠️ 降级。vision_score = 中等代理（插眼多≠预判准）。
              │    deaths < P25 = 弱代理（低死亡可能只是怂）。
              │    kill_participation > P65 = 与宁王/我就是天重叠，区分度不足。
              │    核心语义"预判对手位置"需事件级数据（反蹲成功率），当前不可获取。
              │    → L2裁决：代理强度不足，产品级最高 B。
              │
L3 语义保真    │ SF=9.35 → 语义自洽。"雷达"的字面语义在游戏中成立，
              │    选手剥离度9/10。 → L3裁决：A级语义。
              │
L4 来源可信    │ ✅ Karsa的"雷达哥"来源清晰（LMS/LPL解说+社区命名），P0级。
              │
L5 认知度      │ ✅ 打野位玩家认知度高。
              │
L6 传播力      │ ✅ 中等偏上。
```

**最终裁决**：`L2(可计算性) = ⚠️ 降B` > L3(SF=9.35→A)。**雷达哥产品级为 B sub_tag。**

> **裁决理由**：SF评分体系中SF2=8的高分是因为"vision_score+deaths+kill_participation可逼近"，但这三个指标的代理强度经L2独立评估为中等/弱。雷达哥的核心语义（预判对手位置并反蹲成功）需要事件级数据，当前不可获取。因此，虽然语义映射自洽（L3通过），但数据代理不够强（L2降级），最终产品级为B sub_tag。
>
> **升级路径**：若未来获得事件级数据（反蹲成功率），可重新评估升级至A primary。

> **保留方式**：右手作为左手产品卡的 `aliases` 字段中的一个解释性引用——在"圈内梗解释"中出现一次"Chovy被镜像称为'右手'"，不参与任何触发逻辑，不展示给用户作为称号。
>
> **升级路径**：若Chovy在中国社区产生独立梗（非Knight镜像），可重新评估。

### 3.3 宁王：SF=7.50(B) + H5=4 — 品牌脱敏方案

#### 冲突全景

| 来源 | 判定 | 理由 |
|:----|:----|:----|
| `round-06-semantic-boundary.md` §3.3 | SF=7.50 🟡 B级 | SF1=8(S8冠军打野风格)，SF2=9(可算)，SF3=8("王"字调侃)，**SF4=4**(选手剥离度极低)，SF5=6(负面联想) |

#### 裁决分析（一致项+分歧项）

**一致项**：两份文档均判定宁王为 B sub_tag，均识别了选手绑定问题。

**分歧项**：

| 分歧点 | semantic-boundary | product-card-reconciliation | 裁决 |
|:------|:-----------------|:--------------------------|:----|
| 展示名 | 推荐"莽王"或"敢打敢拼"（去品牌化） | "宁王" | **采纳去品牌化** |
| 品牌脱敏强度 | 强烈建议不使用"宁"字 | 仅禁止"鞋王"，"宁王"可用 | **采纳强脱敏** |

#### L1–L6 逐层裁决

```
L1 安全红线    │ ✅ 通过。"宁王"本身无红线攻击。注意："鞋王"变体为L1 D级禁用。
              │
L2 可计算性    │ ✅ 通过。kill_participation+damage_share+deaths可直接计算。
              │
L3 语义保真    │ SF=7.50 → B级。核心问题在SF4=4（选手剥离度）：
              │    "宁"是选手名（高振宁），"王"是LPL辈分体系（帝>圣>王>酱）。
              │    脱离Ning后，"宁王"字面语义="宁姓的王"或"宁静的王"→
              │    完全失去LOL语义。这是H5硬淘汰的边缘案例。
              │    SF5=6（"宁王别送"负面联想高，社区更常用"宁王"来调侃）。
              │    → L3裁决：B级，必须品牌脱敏。
              │
L4 来源可信    │ ✅ Ning=S8冠军FMVP打野，来源可靠。
              │
L5 认知度      │ ✅ 中高。但注意：新玩家可能不知道Ning是谁。
              │
L6 传播力      │ 高。
```

**最终裁决**：**宁王保留为 B sub_tag，但对外展示使用去品牌化名称（"莽王"），不使用"宁"字。内部数据标签保留"宁王"用于开发沟通。**

> **品牌脱敏方案**：
>
> | 层级 | 使用名称 | 受众 |
> |:----:|:--------|:----|
> | **内部数据标签** | `ning_style` / "宁王型打野" | 开发/运营/数据分析 |
> | **对外展示名** | **"莽王"** | 玩家 |
> | **对外文案** | "你的打野风格敢打敢拼，像一位激进的莽王" | 玩家 |
> | **禁止使用** | "鞋王"、"宁王"（对外） | — |
>
> **脱敏理由**：
> 1. "宁"是选手高振宁的具体名字，脱离选手后字面语义丢失（H5=4）
> 2. "王"字辈在LPL体系中有调侃意味，非纯褒义（SF3=8而非10）
> 3. "宁王别送"的负面联想在社区中广泛存在（SF5=6）

**L1–L6 逐层裁决**：

```

              │

              │    SF5=3（反讽风险）：Xiaohu自2020年后大赛表现不佳，"虎大将军"常与
              │    "2200""虎大捞比"并列使用。社区反讽使用率估计>60%。
              │    → L3裁决：B级，必须自嘲开关+锁定正面触发。

              │
```

**最终裁决**：**虎大将军安全分级从 A 🟢 修正为 B 🟡。产品级 primary（仅正面触发），必须自嘲开关。**

> **修正理由**：product-card-reconciliation §2.4 将虎大将军安全分级标为 A 🟢，但以下证据不支持A级判定：

> 3. "虎大将军"与"2200"在社区中形成反义词对，授予"虎大将军"时社区可能反向解读为"2200"
>
> **A→B修正**意味着：虎大将军需要自嘲开关保护（用户可以选择不接收此称号），而不能像厂长或雷达哥那样无条件授予。

> **反讽风险无法消除的声明**：即使damage_share>P90+kills>P85+胜利的阈值极高，社区仍可能在看到他人被授予"虎大将军"后进行反讽使用（"你看那个虎大将军又送了"）。这是社区行为，不受触发逻辑控制。自嘲开关是产品层唯一的缓解手段。

## 7. 裁决优先级体系的边界条件与特殊情况

### 7.1 代理强度的分级标准（L2细化）

| 代理强度 | 定义 | 典型代理指标 | 对产品级的影响 |
|:------:|:----|:----------|:------------|
| **强代理** | 指标直接测量核心语义，无可替代解释 | kill_participation代理"打野参团率" | 不影响产品级 |
| **中代理** | 指标逼近核心语义，但存在替代解释 | vision_score代理"预判能力" | 产品级最高B |
| **弱代理** | 指标仅间接相关，替代解释占主导 | deaths<P25代理"反打野预判"（可能只是怂） | 产品级最高B sub_tag |
| **无代理** | 核心语义无合理数据近似 | — | 淘汰或降C |

### 7.2 反讽风险的处理边界（L3-SF5细化）

| SF5 反讽风险 | 社区使用特征 | 缓解措施 | 最高产品级 |
|:----------:|:----------|:--------|:--------:|
| **SF5 ≥ 7** | 无反讽或极少反讽（<10%） | 无需特殊处理 | A primary |
| **SF5 5–6** | 中等反讽（10–40%） | 调侃机制消解严肃性 / 极高触发阈值 | B primary/sub_tag |
| **SF5 3–4** | 高反讽（40–70%） | 必须自嘲开关 + 锁定正向触发 | B primary（需自嘲） |
| **SF5 ≤ 2** | 极高反讽（>70%） | 淘汰或仅状态文案 | C 或 D |

### 7.3 认知度的淘汰阈值（L5细化）

| 认知度区间 | 判定 | 产品影响 |
|:--------:|:----:|:-------|
| **> 75%** | 高认知 | 不限制产品级 |
| **60–75%** | 中认知 | 最高B级；需用户验证确认 |
| **< 60%** | 低认知 | 淘汰trigger（可保留aliases）；或降C级状态文案 |
| **< 40%** | 极低认知 | 完全淘汰 |

### 7.4 L1–L6 体系不覆盖的维度

以下维度未纳入L1–L6体系，需在用户验证（Phase 3）或灰度上线（Phase 4）中独立评估：

| 维度 | 为什么未纳入 | 评估阶段 |
|:----|:----------|:-------|
| 分享意愿（T3） | 非梗语义属性，是用户产品体验 | Phase 3 用户验证（n≥250/梗） |
| 冒犯率（T2） | 需要真实用户数据，不可先验判断 | Phase 3 用户验证（n≥250/梗） |
| 自嘲开关的非单调效应 | 需要真实产品内A/B测试 | Phase 4 灰度 |
| 长期累积效应 | 需要纵向数据 | Phase 4+ 长期追踪 |
