#### C-JG-01：绝食流 / 绝食性打野

| 字段 | 值 |
|------|-----|
| **来源** | MLXG（刘世宇）RNG 时期打法风格——放弃自身发育、无限gank/反蹲/开团，靠打架获取经济。解说/社区称之为"绝食性打野"。 |
| **来源等级** | P1（LPL官方解说多次使用"绝食性打野"描述MLXG，萌娘百科MLXG页词条提及） |
| **原始语境** | MLXG 在 S7–S8 时期以极端gank频率著称，经常比对手打野低 2–3 级但带崩三路节奏 |
| **现义** | 打野玩家放弃常规刷野节奏，高频 gank/反野/打架，自身发育落后但带起团队节奏 |
| **映射行为** | 🔵 绝食 + 🟢 gank + 🟢 开团 |
| **位置** | jungle only |
| **可计算性** | ⚠️ 部分可计算：`cs_per_min_avg` < P25（低刷野）+ `kill_participation` > P80（高参团）+ `assists` > P75。但"绝食"核心（主动放弃发育换节奏）需要"在同一时间点对比对手打野等级差"，需事件级数据。 |
| **简化方案** | 用 `cs_per_min_avg` < P25 + `kill_participation` > P80 + `deaths` ≤ P50（不是送死型）逼近"绝食"语义 |
| **降级风险** | 与"暴毙型打野"边界模糊——低刷野+高参团也可能是"送了无数波"的结果。deaths < P50 反证可部分排除。 |
| **反证** | 若 `deaths` > P65 → 不是绝食而是送头；若 `cs_per_min` > P40 → 不是绝食，经济正常 |
| **产品角色** | **B级 / sub_tag（需自嘲开关）** — 语义正面（敢打敢拼），但"绝食"字面给人以"吃不到资源"的负面联想 |
| **风险** | 🟡 "绝食"有健康隐喻（饥饿），部分用户可能不适。建议 UI 附"牺牲发育换节奏"解释文案 |
| **认知度** | lpl_viewer × stable（MLXG 退役后仍被高频提及） |
| **推荐** | 作为 sub_tag 展示，搭配主称号使用，不单独作 primary |

## 3. 核心梗语义对比与风险矩阵

### 3.1 必查梗深度对比

项目要求重点比较以下梗的语义与风险：

#### 🏆 奇迹行者 vs 正方形打野 vs 野王（贬义面）

| 维度 | 奇迹行者 | 正方形打野 | 野王（贬义面） |
|------|:--------:|:----------:|:--------------:|
| **刷野量** | 极高（>P75） | 高（>P65） | 高（>P65） |
| **参团率** | 极低（<P25） | 中（P30–P70） | 中低（P20–P45） |
| **核心语义** | "只刷不帮" | "高效刷+偶尔帮" | "刷得不错但帮得少" |
| **严重度** | 最高（完全局外人） | 中性（战术取舍） | 中低（调侃） |
| **认知度** | ↑ rising | ↓ fading | → stable |
| **风险** | 🟡 teasing | 🟡 fading | 🟠 双面语义 |
| **产品角色** | A级 primary | B级 sub_tag | B级 sub_tag（褒义侧仅用） |

**结论**：三者不是替代关系，而是**严重程度递进**。奇迹行者是"最严重"的只刷不帮，正方形打野是"中等参与"的战术打野，野王（贬义）是"轻度调侃"的刷子。三者可以共存，但触发区间必须互斥——用 `kill_participation` 百分位区分，不可同时触发。

#### 🏆 厂长/4396/777（Clearlove 三件套）

| 维度 | 厂长 | 4396 | 777 |
|------|:----:|:----:|:---:|
| **核心语义** | 野区统治、反野养猪 | 伤害低的计量单位 | 粉丝/幸运数字 |
| **sentiment** | positive (teasing edge) | negative（需自嘲） | positive |
| **可计算** | ✅（高刷野+高视野） | ✅（低伤害占比） | ❌（纯数字无行为映射） |
| **产品角色** | A级 primary（正面） | B级 primary（自嘲） | C级 status（彩蛋） |
| **风险** | 🟡 与4396负面绑定风险 | 🟠 纯贬义需缓解 | 🟢 |
| **综合评估** | ✅ 主称号 | ✅ 自嘲面 | ⚠️ 建议不作为独立称号 |

**关键结论**：「厂长」和「4396」是**同一选手的一体两面**——可以用作正/反两面称号（类似天神下凡 vs 状态低迷）。777 作为纯数字幸运梗，语义太弱，不建议作为独立称号，可作为厂长的配套彩蛋状态。

#### 🏆 绝食流（MLXG） vs 野王 vs 雷达哥

| 维度 | 绝食流 | 野王（褒义面） | 雷达哥 |
|------|:-------:|:-------------:|:------:|
| **刷野量** | 极低（<P25） | 高（>P75） | 中高（P50–P80） |
| **参团率** | 极高（>P80） | 中高（P50–P80） | 高（>P65） |
| **视野** | 中等 | 中等 | 极高（>P85） |
| **核心行为** | 放弃发育换节奏 | 刷野+支援双优 | 预判对手、反制 |
| **sentiment** | positive（敢打敢拼） | positive（统治力） | positive（意识好） |
| **可计算** | ⚠️ 部分可（简化方案） | ✅ | ⚠️ 部分可（简化方案） |
| **风险** | 🟡 "绝食"字面负面 | 🟡 "王"字辈调侃 | 🟢 纯褒义 |
| **产品角色** | B级 sub_tag | B级 sub_tag | **A级 primary** |

**关键结论**：三者覆盖了打野的三种不同风格，不存在直接冲突。雷达哥因纯褒义、无负面联想，最适合作为 **A 级主称号**。

- **开团** ⚠️ 间接覆盖（绝食流、宁王），无专门梗。但开团更偏向"决定开团的指挥行为"，用汇总数据难以精确捕获。
- **保KDA/怂** ⚠️ 4396覆盖了伤害低的负面面，但"刻意保KDA"（不参团保数据）和"刷野不帮"（奇迹行者）有重叠。
- **绝食** ⚠️ 有候选但部分可计算。

   - "龙团猎手"（行为描述 + 自然）
   - "屠龙勇士"（游戏内置成就风格）
   - "龙区死神"（略偏黑但可接受）

   - "你的龙就是我的龙"（社区已有的抢龙弹幕，可做C级状态文案）
   - 注意：需确认该弹幕无选手绑定
