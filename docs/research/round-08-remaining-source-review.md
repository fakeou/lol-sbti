### 2.1 纳尔圣经（Nar Bible）

**基本描述**：Letme（严君泽）在RNG时期队内语音中关于自己纳尔发挥的经典发言。"纳尔圣经"是LPL"四大圣经"之一（Letme版），与Clearlove版、Uzi版、Ning版并列。

**来源核查**：

| 等级 | URL | 状态 | 说明 |
|:----:|-----|:----:|------|
| **P0** | Letme在RNG时期队内语音原始录像——RNG战队官方纪录片或麦克疯系列节目 | ❌ tool_unavailable | RNG官方麦克疯/纪录片视频在B站/腾讯视频有存档，但WebFetch无法从视频页面提取队内语音文本。需人工观看视频确认时间戳 |
| **P1** | 无LOL官方直接收录为"圣经"词条 | ❌ | "圣经"词条（wiki.biligame.com/lol/圣经）收录了Letme版本全文，但该页面为P3社区wiki，非官方P1 |
| **P2** | 搜狐/腾讯新闻同期报道"RNG Letme 圣经" | ❌ tool_unavailable | 相关报道可能存在但未定位具体URL |
| **P3** | `https://wiki.biligame.com/lol/%E5%9C%A3%E7%BB%8F` | ✅ **内容已获取** | 明确收录Letme版圣经全文："就是我说什么你们完全就没有听，我说什么你们也不给我反馈，就我也不知道干什么，就手会一直抖，打了很久，就会一直在莫名其妙抖。" 标注TAG标签包含Letme。更新于2020-07-26 |
| **P3** | B站"圣经"相关切片（多个版本） | ✅ 存在 | 社区广泛传播，Letme纳尔语录+队内语音字幕版切片 |

**origin_verified**：⚠️ **部分成立**
- P3来源（bilibili wiki圣经词条）确认Letme版本存在并收录了完整语录
- "纳尔圣经"特指Letme说这段话时的背景（他玩的是纳尔上单），但RNG麦克疯原始录像（P0）无法通过WebFetch直接定位
- 注意：letme自己职业生涯纳尔玩得很少，这恰恰增加了"圣经"的讽刺意味——他后来被Karsa训"一个赛季练个纳尔那么难吗"正是对此的呼应
- R3 ledger §一#14 对"圣经"有收录，确认四大圣经的存在

**meaning_verified**：✅ **成立**
- 语义："我说什么你们都不听→没有反馈→手抖→心态崩了"。描述的是Letme在RNG时期因缺乏团队沟通反馈而产生的焦虑、失控和心态崩溃
- LPL社区共识极强，是"圣经"四大版本之一，也是"心态爆炸"的经典代表文本
- 具体到"纳尔圣经"：语义是**上单选手因团队沟通缺失而心态崩溃、操作变形**——核心是"沟通崩溃→心态失衡→上单自闭"

**语义可泛化度**：🟡 **中**
- "纳尔圣经"脱离Letme后可泛化为"任何因团队沟通缺失而心态崩溃的上单玩家"
- 但其强绑定Letme个人经历（RNG时期队内氛围）和纳尔这个英雄，脱离具体语境后语义损耗大
- 社区使用习惯是用"圣经"指代整个经典语录文本，而不是直接用"纳尔圣经"描述其他人的行为。泛化程度低于"拉扯圣经"

**可计算性**：🟡 **中低**
- core_signal：沟通参与度（ping数/打字/语音活跃度）持续走低 + 操作变形（失误率上升）
- 触发条件可设置为：communication_freq<P25 + misplay_rate>P75 + 上单位 + 持续时间>5min
- 但"心态崩溃"本身不可直接观测，只能通过失误率和沟通参与度间接代理
- 语义精度：粗糙。无法区分"纳尔圣经式心态崩溃"和"普通心态爆炸"

**安全层级**：🟢 **Safe**
- 无人身攻击或侮辱性内容。原始语义是选手的真诚表达
- 仅在用于嘲讽玩家"心态差"时可能引起轻微负面感受
- 建议使用场景：单局status文案（触发时显示"No one is listening..."类彩蛋）

**产品层级建议**：🟡 **Sub-tag / Status-only**
- 不适合做primary长期称号——它强绑定Letme个人经历
- 推荐作为单局status彩蛋，在检测到上单玩家沟通参与度骤降+失误率飙升时触发
- 需要自嘲开关（因为可能暗示队友不沟通）

- 但精确检测需要语音文本分析（comms keyword spotting），纯游戏数据无法捕捉
- 语义精度：如果只用游戏数据，"拉扯圣经"和"普通菜鸟团战行为"难以区分

**安全层级**：🟢 **Safe**
- 无攻击性内容。"拉扯圣经"的核心是调侃理论派，不是人身攻击
- 但需注意不要过度暗示玩家"纸上谈兵"——可能触发负面感受

**产品层级建议**：🟡 **Sub-tag**
- 语义泛化度高于纳尔圣经，但仍需要LPL社区知识才能完全理解
- 推荐sub-tag，在检测到玩家comms中存在高频率"拉扯/团战/开团"类指令但实战团战表现不佳时触发
- 彩蛋属性强，适合作为幽默反馈

**origin_verified**：⚠️ **部分成立**
- P1（解说使用"世界第一上单"）可作为官方佐证，但"世一上"作为缩写称号并非解说首创，而是社区从"世界第一上单"缩略而来
- 没有单场首创时刻——"世一上"是TheShy巅峰期长期表现产生的总结性称号
- 类似"厂长"（Clearlove）的起源模式：选手ID + 成就 → 社区称号

- 原始语义（S8-S9）：对TheShy的表现称赞，世界第一上单
- 当前语义（S10后）：已从纯褒义转向双刃——在称赞TheShy当前表现时仍为褒义，但社区中也广泛用于**反讽**（一个上单送人头时弹幕刷"世一上"）

**语义可泛化度**：🟢 **高**
- "世一上"字面语义自明：世界第一上单。即使非LPL观众也能理解

- 相比"厂长"（需要LPL知识），"世一上"的字面语义几乎不需要社区知识

- 语义精度较好——高数据 + 上单位 = 合理的"世一上"授予条件
- 需要注意反讽阈值：当数据极差但授予"世一上"时触发反讽语义

**安全层级**：🟡 **需自嘲开关**

- 与"虎大将军"类似：系统授予的是褒义，但接收者可能理解为反讽
- 强制自嘲开关是必要的

**产品层级建议**：🟢 **Primary ✅**
- 语义自明，通用性高，可计算性强
- 选手剥离度中等——脱离TheShy后仍保有"世界第一上单"的字面语义
- 产品卡推荐：上单位 > performance > 世一上。授予条件：damage_share>P90 + gold_diff@15>P90 + 上单位 + 胜利
- 建议配备自嘲开关 + 反讽阈值检测（数据极低时授予meta成就"世一上（？）"）

### 3.3 关键发现

#### 发现1：2200是唯一origin_verified的项

8项中有7项无法通过WebFetch实现严格的origin_verified。仅**2200**具备完整的证据链：P0（S9比赛VOD可定位）+ P3（bilibili wiki收录，明确记录比赛/选手/英雄/伤害数值）。其余7项要么无单场首创时刻（世一上、绝食流、暴毙AD、装杯），要么P0/P1/P3均不可通过WebFetch验证。

#### 发现2：3项适合Primary产品化

**世一上、绝食流、红温**三项语义自明、可计算性高、安全层级可接受，适合作为primary称号产品化：
- **世一上**：上单位 > performance > 世界第一上单。数据条件+自嘲开关，处理双刃语义
- **绝食流**：打野位 > playstyle > 不吃资源的gank型打野。语义干净，无安全风险
- **红温**：通用 > state > 心态爆炸。数据代理合理，适合post-game反馈

**暴毙AD**虽可计算性高，但因来源弱（无P0/P1/P3），建议先加强来源再升primary。

#### 发现3："拉扯圣经"有较高的泛化潜力但缺乏来源支撑

"拉扯圣经"的语义（理论高手/纸上谈兵）是8项中**泛化潜力最高的**，可以脱离LOL语境独立使用。但：
- 原始文本无法通过WebFetch获取（bilibili wiki 404）
- R3 ledger无独立审计
- 如果后续团队能补充原始录音文本，建议重新评估

#### 发现4：纳尔圣经和2200共享部分语义生态位

两者均与Xiaohu/RNG相关且均涉及"中单摆烂/输出低"：
- 2200 = 伤害数据层面的低（全场2200输出）
- 纳尔圣经 = 心态层面的崩（沟通缺失→心态爆炸）
- 产品化时应注意避免同一个产品卡同时使用两个与Xiaohu绑定的标签

#### 发现5：装杯是唯一的非LOL特有项

"装杯"是8项中**唯一不是LOL独有梗**的——它是中文网络通用语"装逼"的谐音变体。LOL社区使用频率高但无LOL独有语义。这对于产品化是双刃剑：
- 优势：用户不需要LOL知识就能理解
- 劣势：没有LOL社区身份认同感，产品"得有个梗"的价值降低
