本轮的筛选逻辑：

```
R8 20+1 产品卡
  │
  ├── 门1: 传播触发力（玩家看到后是否想截图/告诉朋友/主动触发）

  └── ✅ 通过 → 16 项梗包（默认开启 7 + 自嘲开关 5 + 仅状态 1 + 证据待补 3）
```

### 1.1 天神下凡

| 维度 | 内容 |
|:-----|------|
| **位置** | Any（跨位置） |
| **R8 层级** | 核心层 |
| **产品级** | A primary |

#### 为什么有传播力 🏆 荣誉勋章

- **最强来源链**：P0（S8 半决赛 IG vs G2 第2场 VOD 可定位）+ P1（LOL 官方认证）+ P2（搜狐同期报道）——三条独立来源交叉验证，是整个梗包中来源最强的一项。
- **语义完全自明**：「天神下凡」四个字不需要任何选手知识——任何中文 LOL 玩家看到都能立刻联想到「一个人carry全场的团战表现」。
- **社交货币类型**：🏆 荣誉勋章。玩家被授予「天神下凡」的瞬间 = 截图发朋友圈的冲动。这是整个梗包中**最具分享驱动力的单卡**。
- **零反讽风险**：社区使用率 > 90% 为正面褒义。不存在「你看那个天神下凡又送了」的反讽用法。R6 SF5=10。
- **认知度**：> 90%。几乎所有中文 LOL 玩家（无论是否看 LPL）都知道「天神下凡」= TheShy 剑魔名场面。

#### 触发所需现有字段

| 字段 | 来源 | 用途 |
|:-----|:-----|:-----|
| `kills` | CsvMatch | 击杀数 |
| `deaths` | CsvMatch | 死亡数 |
| `kill_participation_percent` | CsvMatch（computed） | 参团率 |
| `damage_share_percent` | CsvMatch（computed） | 伤害占比 |
| `result` | CsvMatch（win/loss） | 胜利 |
| `position` | CsvMatch | 可选：若位置限定版本则用于过滤 |

**触发条件**（单场）：
```
kills ≥ 8 且 deaths ≤ 2 且 kill_participation_percent ≥ P90 且 damage_share_percent ≥ P85 且 result = "胜利"
```

> **注意**：R5 产品卡原设计为 `kda>P95 + damage_share>P85 + quadra_kill`。当前字段无 `quadra_kill`（multiKill 数据在 LCU match detail 中存在但未提取到 CsvMatch），v1 使用 kills/ deaths 替代。若 v1.1 扩展 CsvMatch 加入 multiKill 字段，可提升触发精度。

#### 误触防线

| 防线 | 规则 | 拦截场景 |
|:-----|:-----|:-----|
| **胜利门** | `result = "胜利"` | 杀人多但输了——那是尽力局，不是天神下凡 |
| **死亡上限** | `deaths ≤ 2` | 杀人多但死得也多——互换型选手，不是碾压 |
| **伤害占比** | `damage_share_percent ≥ P85` | K头型选手（高击杀低伤害）——数据好看但团战不是他carry的 |
| **模式限定** | 仅排位模式（ranked_solo / ranked_flex） | 大乱斗/人机模式不触发 |

#### 解释文案

> ⚡ **天神下凡**
>
> *那一波你一个人冲进去，对面四个人全倒了。*
>
> 你本局击杀 **{kills}**，死亡仅 **{deaths}**，伤害占比 **{damage_share_percent}%**。
> S8 半决赛 TheShy 剑魔 1v4 的名场面，后人称之为「天神下凡」。
> 你这一局，当得起这三个字。

### 1.2 369骰子

| 维度 | 内容 |
|:-----|------|
| **位置** | Top（上单） |
| **R8 层级** | 实验层 |
| **产品级** | A primary |

#### 为什么有传播力 🎲 自嘲硬币 + ⚡ 情绪共鸣

- **独立语义锚点**：「骰子」= 不确定性/随机性，这是完全不依赖选手的通识概念。一个不了解 369 选手的玩家看到「369骰子」虽然不知道「369」是谁，但「骰子」两字已足以触发「上下限差距极大」的理解。
- **数字梗天然传播**：「369」三个数字简洁、易记、易成为口头禅。"你这把369了"在中文 LOL 社区已是半通用表达。
- **自嘲驱动分享**：玩家被标注为「摇到3」时，幽默化解尴尬的冲动天然驱动分享。这是**自嘲型传播**中最强的社交货币。
- **R8 裁决**：独立语义锚点「骰子」成立，但「369」数字绑定选手 ID。语义可泛化度高。

#### 触发所需现有字段

| 字段 | 来源 | 用途 |
|:-----|:-----|:-----|
| `kills` | CsvMatch | KDA 计算 |
| `deaths` | CsvMatch | KDA 计算 |
| `assists` | CsvMatch | KDA 计算 |
| `damage_share_percent` | CsvMatch（computed） | 伤害占比 |
| `position` | CsvMatch | 位置过滤（上单） |

**触发条件**（跨场聚合，≥15场/90天）：
```
kda_variance > 同位置上单 P80
  且 damage_share_percent_variance > 同位置上单 P70

反证（任一成立则不触发）：
  win_rate > 60% 且 kda_variance 在 P50-P70（高风险高回报正常打法）

副标签动态：
  "今天摇到9": 近5场 avg_kda > P85 且 win_rate ≥ 80%
  "今天摇到6": 近5场表现 P40-P60
  "今天摇到3": 近5场 avg_kda < P25 且 win_rate ≤ 40%
```

> **计算成本注**：需要跨场聚合（≥15场），非单场触发。需在后端做聚合计算而非前端 CsvMatch 直接判断。

#### 误触防线

| 防线 | 规则 | 拦截场景 |
|:-----|:-----|:-----|
| **样本量** | 最少 15 场同位置对局 | 新手玩家数据不稳定≠369式波动 |
| **高风险豁免** | win_rate > 60% + 中等方差 = 豁免 | 正常的高风险高回报打法，不是不稳定 |
| **位置限定** | 仅上单位 | 其他位置不存在「369骰子」语义 |
| **副标签动态更新** | 摇到9/6/3 随近5场动态变化 | 避免永久贴上某一面标签 |

#### 解释文案

> 🎲 **369骰子**
>
> *你是对面和队友都猜不透的男人。*
>
> 近 20 场你的 KDA 从 **{kda_min}** 到 **{kda_max}** 横跳了 **{swing_count}** 次，
> 伤害占比从 **{dmg_min}%** 到 **{dmg_max}%** 来回摩擦。
>
> 上单选手 369 因发挥极度不稳定被戏称为「摇骰子」——摇到 3 拉跨，摇到 6 平庸，摇到 9 天神。
> 今天你摇到了 **{current_roll}**。

### 1.3 暴毙AD

| 维度 | 内容 |
|:-----|------|
| **位置** | Bottom（ADC） |
| **R8 层级** | 实验层 |
| **产品级** | A primary |

#### 为什么有传播力 ⚡ 情绪共鸣

- **语义完全自明**：「暴毙」= 突然死亡，「AD」= 射手位置。不需要知道 JackeyLove 或 Uzi 是谁即可理解。
- **团战场景天然适配**：ADC 在团战中被秒是 LOL 最经典的悲剧场景，任何一个 ADC 玩家都经历过——共鸣面积极广。
- **调侃非侮辱**：「暴毙AD」偏向幽默调侃而非人身攻击。社区使用已泛化，不限于特定选手。
- **R8 裁决**：语义可泛化度 🟢 高。字面语义自明。

#### 触发所需现有字段

| 字段 | 来源 | 用途 |
|:-----|:-----|:-----|
| `deaths` | CsvMatch | 团战死亡次数 |
| `damage_taken` | CsvMatch | 承受伤害量（爆发伤害代理） |
| `position` | CsvMatch | 位置过滤（ADC） |
| `duration_minutes` | CsvMatch | 对局时长（用于归一化） |

**触发条件**（单场）：
```
position = "Bottom"（ADC位）
  且 deaths ≥ P85（同位置ADC）
  且 damage_taken / deaths < P15（每次死亡承受伤害极低 → 被秒杀而非肉搏致死）

辅助条件（可选，提升精度）：
  kill_participation_percent < P40（死得多但参团率低 → 纯送非换命）
```

> **精度注**：当前 CsvMatch 无 `teamfight_death_time`（团战死亡时刻）和 `burst_damage_received`（爆发伤害占比）。v1 使用 `deaths + damage_taken/death` 作为间接代理——死得多且死得快（被秒）推断为「暴毙」。精度中等，v1.1 如有团战事件级数据可大幅提升。

#### 误触防线

| 防线 | 规则 | 拦截场景 |
|:-----|:-----|:-----|
| **死亡质量过滤** | `damage_taken / deaths ≥ P50` 豁免 | 虽然死得多但每死都扛了大量伤害——坦克型AD或换命打法，不是暴毙 |
| **胜利豁免** | `result = "胜利"` 且 `kill_participation_percent ≥ P60` | 虽然死了但团战打出足够输出——可接受的牺牲 |
| **位置限定** | 仅 ADC 位 | 坦克/战士被秒不是「暴毙AD」语义 |

#### 解释文案

> 💀 **暴毙AD**
>
> *团战刚开始，你先倒下了。*
>
> 本局你阵亡 **{deaths}** 次，每次死亡平均仅承受 **{avg_damage_per_death}** 伤害 —
> 你每次都是被瞬间蒸发，队友还没来得及反应。
>
> 「暴毙AD」源自 LPL 社区对 ADC 团战被秒的经典调侃。
> 下次团战，站后一点？

### 1.4 绝食流

| 维度 | 内容 |
|:-----|------|
| **位置** | Jungle（打野） |
| **R8 层级** | 实验层（R8 补位复核推荐 Primary） |
| **产品级** | Primary（候选） |

#### 为什么有传播力 🏆 荣誉勋章 + 🔮 身份符号

- **打法风格标签**：「绝食流」描述一种具体的、可理解的打野玩法流派——让资源给队友，靠 gank 和控制地图取胜。语义自明（"绝食"=不吃资源）。
- **MLXG 绑定但语义独立**：虽然起源于 Mlxg，但「绝食」+「流」的字面组合不需要知道 Mlxg。任何打野玩家都能理解「放弃刷野去 gank」的打法。
- **正向激励属性**：授予「绝食流」隐含的意思是「你牺牲了个人经济但为团队创造了优势」。这是一种隐性表扬，符合 🏆 荣誉勋章分享心理。
- **R8 来源审计**：起源 ⚠️ 部分（Mlxg 绑定），语义 ✅ 成立（bilibili wiki 词条确认）。产品级推荐 Primary。

#### 触发所需现有字段

| 字段 | 来源 | 用途 |
|:-----|:-----|:-----|
| `cs` | CsvMatch | 补刀数（计算 cs_per_min） |
| `kill_participation_percent` | CsvMatch（computed） | 参团率 |
| `vision_score` | CsvMatch | 视野得分（控图代理） |
| `position` | CsvMatch | 位置过滤（打野） |
| `duration_minutes` | CsvMatch | 对局时长（归一化 cs_per_min） |

**触发条件**（单场）：
```
position = "Jungle"（打野位）
  且 cs_per_min < 同位置打野 P25（显著低于平均刷野量）
  且 kill_participation_percent > P75（高频参团）
  且 vision_score > P70（控图积极）

反证（任一成立则不触发）：
  deaths > P85 且 kill_participation_percent < P50
  → 不是「绝食流」，是被反炸了吃不到资源（被动绝食）
```

#### 误触防线

| 防线 | 规则 | 拦截场景 |
|:-----|:-----|:-----|
| **被动绝食过滤** | 高死亡 + 低参团 + 低视野 → 不触发 | 被对方打野反炸了，野区被清光——不是主动让资源 |
| **胜利倾向** | `result = "胜利"` 时阈值可适当放宽 | 赢了的绝食流是有效打法；输了的绝食流可能是被碾压 |
| **位置限定** | 仅打野位 | 其他位置低 CS 不是「绝食流」语义 |

#### 解释文案

> 🍽️ **绝食流打野**
>
> *你自己的野区几乎没碰，但队伍的三路都被你帮穿了。*
>
> 本局你每分钟补刀仅 **{cs_per_min}**（同位置后 25%），
> 但参团率高达 **{kill_participation_percent}%**，视野得分 **{vision_score}**。
>
> Mlxg 式的「绝食流」打法：不吃资源，只干人事。
> 你的队友应该请你吃饭。
