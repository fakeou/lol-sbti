## 1. 桌面端

### 1.1 主页面

```text

│ │ 可读取 50 场（目标最多 100 场）           │ │
│ │ 时间：06-28 — 07-23                      │ │
│ │ 模式：单双排 31 / 大乱斗 19              │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ 将上传：脱敏战绩与统计指标                   │
│ 不上传：LCU Token、账号 ID、对局 ID、玩家名  │
│ 数据保留：报告 24 小时；链接 30 分钟         │
│ [查看完整字段和隐私说明]                     │

│                                              │
│ 也可：[仅导出本地 CSV]                       │
└──────────────────────────────────────────────┘
```

### 1.2 交互

- LCU 未连接时主按钮禁用，并提供“启动并登录英雄联盟客户端”的明确提示。
- 采集完成后显示实际样本量；不能把 LCU 实际返回 50 场伪装成 100 场。
- 上传前必须由用户主动点击，不默认勾选显示名，不静默后台上传。
- “查看完整字段”打开本地 modal，列出上传和不上传字段、模型供应商与保留期。
- 本地 CSV 是独立次要操作，不与上传绑定。

### 1.3 状态变体

```text
连接中 → 可预览 → 待用户确认 → 上传中 → 排队中 → 分析中 → 完成
  │          │           │          │         │
  └错误提示──┴样本不足───┴取消/重试──┴可关闭应用继续处理
```

移动端不依赖 hover；图表必须同时提供文字和数值，不能只靠颜色表达。

### 2.3 页面状态

| 状态 | 页面行为 |
|---|---|
| secret 正在兑换 | 骨架屏，不显示报告 ID或错误细节 |
| 链接错误 | “链接无效或已失效”，不区分不存在与 secret 错误 |
| 已过期/撤销 | `410` 页面，解释报告无法恢复 |
| session 有效 | 展示报告；响应 `no-store` |
| 数据字段缺失 | 隐藏局部卡片并展示“该维度样本不足”，不编造默认值 |

## 3. 组件树

```text
DesktopApp
├─ ConnectionStatus
├─ MatchPreview
├─ PrivacyDisclosure
├─ UploadAction
├─ AnalysisProgress
└─ CompletedActions

ReportPage
├─ ExpiryBanner
├─ ReportHero
├─ DimensionScores
├─ SampleSummary
├─ InsightList
├─ RecommendationList
└─ LimitationsNotice
```

`packages/ui` 可以共享颜色、字体、间距和基础卡片，但桌面业务组件与网页报告组件应分别位于各自 app，避免跨运行时耦合。
