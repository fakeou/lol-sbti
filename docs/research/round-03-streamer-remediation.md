## 1. 方法论

### 1.1 本轮核查协议

```
对每条候选主播梗：
1. ✅ 是否有原视频/官方转载/稳定BV号可查（B站优先）
2. ✅ 是否与具体游戏行为（英雄/技能/位置/操作）直接相连
3. ✅ 语义是否可映射为不超过3个游戏指标
4. ✅ 是否有反证规则防止误触发
5. ✅ 是否不涉及攻击性/外貌羞辱/现实人格
6. ❌ 是否已过度泛化（失去LOL专属语义）
7. ❌ 是否为主播个人IP梗而非游戏行为梗
8. ℹ️ 产品层级：primary / sub_tag / status / hidden
```

### 1.2 来源可信度标注

| 标签 | 含义 |
|------|------|
| **[OBS]** | 亲自搜索观察验证（B站播放量、搜索结果） |
| **[CIT]** | 引用可靠百科/官方/新闻 |
| **[INF]** | 基于多个来源推断 |
| **[VERIFIED]** | 原视频BV号可直接验证 |
| **[UNA]** | 当前方法无法获取 |

### 4.1 ❌ 淘汰：下饭

| 维度 | 内容 |
